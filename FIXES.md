# Исправления локальной версии — 20 октября 2026

Исправлена бесконечная повторная выдача заданий с DOCX/XML/DWG. Весь состав комплекта сверяется с неизменяемым manifest, включая SHA, стадии и принадлежность объекту. Детерминированная ошибка завершает свою проверку и освобождает очередь. Временные ошибки сохраняют повторные попытки.

Текущий профиль извлекает текст из PDF. DOCX/XML принимаются, а неподдерживаемый анализ явно обозначается как пропуск: без выдуманных страниц, координат и отрицательных заключений. Ранее принятые DWG также больше не блокируют очередь. Новые DWG отклоняются с `503 DWG_VALIDATOR_UNAVAILABLE`: декодер CAD отсутствует, следует экспортировать чертёж в PDF. Заголовок AC10 больше не считается проверкой структуры.

Аудит исходного текста выполняется отдельно от инженерной проверки. Миграция `052_source_audit_side_lane.sql` восстанавливает ссылки только у затронутых OPEN-проверок; FINAL, история и байты протоколов сохраняются. Интерфейс учитывает реальные объектные права и lifecycle. FINAL запрещает изменение комплекта и новый запуск с понятным `409 INSPECTION_FINALIZED`; отзыв требует роли и права REVOKE.

Поддержан корректный XML из четырёх байт без изменения его размера. Для этого обновлены согласованные API/worker transport и SHA профиля V13. Прежний точный сохранённый V13 release разрешён только для чтения завершённых результатов; новые задания используют текущую конфигурацию. Принятый V12 capsule, каталог и политика уверенности не изменялись.

При обновлении необходимо пересобрать и согласованно обновить API, outbox-relay, migrate, все четыре worker-сервиса и web. Используйте штатный запуск проекта; перед миграцией сохраните резервную копию БД. Старые миграции 001–051 не изменялись. Для 052 автоматического обратного изменения указателей нет; rollback-файл явно отказывает в таком откате.

Проверены полная web suite (1369 тестов), 170 целевых API-тестов, 38 API/PostgreSQL-тестов исправлений, 26 Python-тестов и 16 тестов исторических/текущих миграций. Наборы частично пересекаются. Живые сценарии проверялись на локальном CPU-стенде; это не подтверждение работы GPU/OCR/LLM или независимой инженерной точности.

Этот Git-репозиторий содержит полный исправленный исходный код; накладывать ZIP исправлений не требуется. Начните с [README](README.md) и [CPU-инструкции](docs/operations/CPU_LOCAL_QUICKSTART.md). Файл `SHA256SUMS`, если присутствует, относится к первоначальной архивной поставке и не является контрольной суммой текущего Git checkout; актуальные файлы определяются Git revision.
