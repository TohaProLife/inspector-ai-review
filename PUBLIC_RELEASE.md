# Публичный снимок исходного кода

Этот репозиторий подготовлен для просмотра решения команды «ИИ Друны». Он создан из commit `9a6a04dc398366642f5656c7d6c7ce4b739a715d` закрытого рабочего репозитория `FreeTok/HackatonAI` как новый снимок **без истории Git**.

Исходный код приложения, API, workers, миграции, инструкции и три небольших JSONL-файла справочных данных, необходимые для запуска API, сохранены. Для публичной передачи исключены:

- сторонние изображения Mobbin для внутреннего дизайн-анализа;
- конкурсные PDF, производные изображения и наборы данных, для которых не подтверждено право общего распространения;
- архитектурные WebP с неустановленным происхождением; в этом снимке анимация дома использует оригинальный SVG-чертёж;
- локальные файлы, секреты, модели, зависимости и результаты работы сервисов.

Небольшие PDF в тестах API и `scripts/fixtures/smoke.pdf` — синтетические проверки формата. Некоторые тесты и инструкции, использующие исключённый конкурсный корпус, требуют предоставления этих файлов отдельно по правилам организатора. Не считайте такой тест пройденным на одном этом снимке.

Публичного HTTPS-стенда полного приложения этот репозиторий не заменяет. Для загрузки и анализа документов нужны API, PostgreSQL, RabbitMQ, антивирус и workers. Актуальные ограничения и сценарий запуска указаны в [README](README.md) и [документации](docs/README.md).

Собственная лицензия проекта не добавлена: условия использования исходного кода определяют правообладатель и правила конкурса. Лицензии включённых сторонних зависимостей приведены в соответствующих файлах notice и lockfile.
