# Матрица источников для 47 кандидатов

`scripts/build-candidate-source-matrix.py` строит воспроизводимый план поиска
источников по открытым метаданным. Вход: только `document_manifest.jsonl`
пакета `УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ` и закреплённый пакет
`parameter-candidate-rules-v1.json`. Файлы PDF, TXT и закрытые ответы скрипт
не открывает. SHA-256 манифеста зафиксирован как
`853225daec1888fbed19bbeb45e958154135f069799cea883dcd3c754c6c4ee7`.
Инвентарь обязан содержать 203 разрешённые записи, из них 202 PDF на 10 142
страницах и F0194 только как метаданные.

```bash
PYTHONPATH=services/worker python3 scripts/build-candidate-source-matrix.py \
  --output output/candidate-source-matrix.json
```

Для каждого кода отчёт перечисляет источники отдельно по объекту и роли:

- `exactSourceIds` — PDF с точной стадией ПД либо РД и соответствующей
  **категорией манифеста**. Это кандидаты на чтение, не доказанная пара фактов.
- `unresolvedSectionSourceIds` — стадия подходит, но категория `OTHER` либо
  само правило не имеет однозначной категории. Эти источники требуют проверки
  раздела внутри документа; в `exactSourceCount` они не входят.
- `mixedStageSourceIds` — категория подходит, но стадия `RD_ID_MIXED`.
  `mixedStageUnclassifiedSourceIds` вдобавок имеют `OTHER`. Для них нужен
  разбор стадии конкретного листа.
- `sameObjectExactSourcePairAvailable` — у объекта есть хотя бы один
  предварительный источник ПД и РД. Флаг не проверяет общую редакцию,
  согласование, элемент, величину и читаемость.

Расчёт на зафиксированном открытом манифесте: 36 кодов не имеют однозначной
категории ожидаемого раздела, 14 — фактического. Только KR-061, KR-062 и
KR-067 имеют хотя бы одну пару точных категорий и стадий **в пределах одного
объекта**: для `OBJ-NOVOSLOBODSKAYA` это ПД/КР F0105–F0107 и РД/КР F0136,
F0139–F0144. У `OBJ-TYUMENSKAYA-5-GOLD-SEED` есть ПД/КР F0158–F0159, но
нет точной РД/КР; смешанная стадия не подставляется автоматически.

Следующий шаг для каждого семейства: выбрать источники, проверить индекс и
качество страниц, при необходимости вызвать адресный OCR, затем извлечь
факты с локаторами и подтвердить раздел листа, стадию, редакцию,
согласование и тождество элемента. При отсутствии любого звена результат
`ABSTAIN`. Матрица имеет `SOURCE_PLANNING_ONLY_ABSTAIN`, не исполняет правила,
не добавляет findings и не меняет coverage.
