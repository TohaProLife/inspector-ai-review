# SPZU-029/032: кандидаты соседства блоков таблиц

28 сентября 2026. На оригинальном разрешённом публичном `F0126`
(PDF SHA-256 `b4846376535dd97aa24a8e384e0cb71f40792084fc61981dad587b15bbf63088`)
проверены листы 20 и 21. Исходные рендеры и буквальный контекст описаны в
[визуальном аудите](SITE_GP_CONTEXT_VISUAL_AUDIT_20260928.md).

`document-text-v2` хранит рамку текстового **блока**, а не отдельной строки
или ячейки. Чистый извлекатель `site-gp-table-row-proposals-v1` предлагает
только навигационные пары соседних блоков под точными заголовками. На p.20
получено 21 предложение для слоёв дорожной одежды и 3 отказа из-за
неоднозначности; на p.21 — 11 предложений «позиция — наименование МАФ».
Количество МАФ в сохранённом результате `null`, статус `UNKNOWN`.

Каждое предложение получает `ROW_ASSOCIATION_UNVERIFIED`; единица толщины
и тип конструкции также не подтверждены. Результат всех кодов — `ABSTAIN`,
`findingCount` и `parameterCoverage` равны `null`. Сам факт соседства
блоков не доказывает принадлежность одной строке таблицы. Положительные
факты, сравнение ПД/РД и полнота перечня не заявляются.

В запуск предложения могут войти лишь из сохранённого текстового артефакта
с SHA исходного PDF и immutable решением `CURRENT`/`APPROVED` для ПД/ГП.
По F0126 такого решения нет; ожидаемый рабочий результат на открытом
корпусе — ноль допустимых предложений. Будущая проверка строки потребует
отдельной неизменяемой геометрии строк/ячеек и визуального решения
эксперта по исходному листу. Текущий модуль не создаёт такое решение.

Чистый worker test проверяет синтетическую геометрию, неоднозначность,
ограничение объёма, отказ при подмене SHA и оригинальный F0126.
Отдельный opt-in release `typed-pz002-pz017-site-gp-table-row-review-v1`
подключён в worker/API/web. API независимо пересчитывает source/text SHA,
геометрию, предложения, отказы и причины при save/seal/GET. Синтетические
положительные пути и подмены прошли PostgreSQL тесты; полный локальный
`npm run check` и последовательный PostgreSQL suite 12 файлов/36 тестов
прошли. [Изолированный Compose на F0126](SITE_GP_TABLE_ROW_COMPOSE_20260928.md)
завершился двумя `ABSTAIN` и нулём предложений: реального решения по
источнику нет. Это проверяет сохранение и безопасное воздержание, не
точность соединения ячеек.
