# OCR-строки таблиц: opt-in сквозная проверка F0202

Новый release profile
`typed-pz002-pz017-ocr-heat-fact-family-candidate-preview-observations-ocr-table-v1`
добавляет **некодированные предложения для ручной проверки** к прежним семи
выходам rule stage. Профиль выбирается только через
`INSPECTOR_OCR_TABLE_ROWS_PROFILE=v1`, требует OCR v4/v5 и уже включённый
`candidate-family-ocr-observations-v1`. Старый release profile и облегчённая
конфигурация остаются доступными без нового флага.

Worker формирует пары из сохранённой bounded OCR-стадии, сверяя её SHA,
страницы, строки, оценки и геометрию. API независимо пересчитывает пары из
сохранённой OCR-стадии при сохранении, sealing и чтении результата. Выход не
содержит кода параметра, нормализованного значения или выводов о нарушениях.
Web показывает исходные OCR-строки, локаторы, SHA и причины воздержания.

открытый F0202. Новый run `CHK-1BD8477F` из `CHK-C2D19963`: **10/10 jobs
