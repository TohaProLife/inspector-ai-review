# Ограниченный OCR v4: восстановление повреждённого титула

`local-bounded-ocr-layout-v4` — opt-in профиль для новых запусков. Его
канонический SHA-256 `5b01babba10817bdabbfaaa72f3fc957ef3f8fc4be5bf70fd78c42f87117944c`
совпал в API и worker. Профиль сохраняет предметный выбор v3: если
текстовые якоря РД-ОВ ограничивают страницы `OCR_REQUIRED`, выбираются они.
Когда таких кандидатов нет, v4 рассматривает только физические страницы
1–2 с `OCR_REQUIRED` и причиной `TEXT_DECODING_ANOMALY`. Остальные причины
не запускают этот fallback. Общий предел — две страницы на запуск, 120 dpi,
25 млн пикселей на страницу, 64 МиБ на PDF. Выбор и счётчики независимо
пересчитывает API перед сохранением артефакта. OCR остаётся материалом для
проверки, а не доказанным параметрическим фактом.

Для изолированного Compose homeserver выбран
`INSPECTOR_OCR_LAYOUT_SELECTION_PROFILE=v4`. Конкурсная инструкция и
проверка конфигурации теперь также выбирают v4; действующий `.env.server`
этим не менялся, H100 runtime не проверялся. Лёгкий локальный профиль
сохраняет v1. Предыдущие immutable release v1–v3 читаются по своим версиям.
