# Количественная сопоставимость пары OCR_ROW: отдельный ручной gate

## Контракт

Миграция `028_ocr_fact_pair_quantity_reviews.sql` хранит append-only решения
`SAME_SCALAR_TOTAL`, `NOT_COMPARABLE`, `UNSURE` для точной пары фактов и
неизменяемого снимка решения о паре **следующего** run. Решение в текущем run
без снимка не годится: API возвращает `OCR_QUANTITY_SNAPSHOT_REQUIRED`.
Последнее отрицательное или неопределённое решение перекрывает положительное.
Если в текущем run после снимка пары появляется новое решение по той же паре,
сервер убирает quantity-кандидата и запрещает POST до следующего запуска;
preview возвращает `ABSTAIN/PAIR_SUPERSEDED_IN_CURRENT_RUN`. Старый
`Idempotency-Key` не обходит этот запрет. Запоздалое изменение журнала во
время построения preview приводит к ошибке и повторному чтению.

Валидатор независимо повторяет проверку типизированного OCR_ROW артефакта,
пары, двух source-review снимков, версии каталога, кодов, единиц, страниц,
локаторов и ненулевого значения ПД. Человек отдельно подтверждает, что оба
значения являются одной суммарной величиной для одинаковой области, типа,
периода и способа агрегации; для `SM-132` требуется ценовой базис. Знаменатель
ПД подтверждается явно. Клиент не передаёт `evidenceHash`: сервер вычисляет
его по проверенному решению и происхождению. При чтении журнал проверяется
повторно. Это **review-only** решение: сравнения, покрытия и замечания не
создаются. Численный comparator подключён только к отдельному
аутентифицированному read-only GET. Он получает решение из перепроверенного
журнала, а не из клиентского payload, и выдаёт `REVIEW_ONLY` preview.
Запись сравнений в release/save/seal, findings и coverage не включена.

После подключения read-only preview повторный полный локальный check прошёл:
API 255/255 (+30 skip), web 46/46, worker 663/663, сборка успешна.
Synthetic PostgreSQL проверил положительный расчёт, отрицательный override,
подмену и гонку появления нового решения между чтениями. Обновлённые API/web
пересобраны в том же изолированном Compose; повторный API и браузерный smoke
на `CHK-69B4215C` прошли.

Публичный корпус не содержит утверждённой человеком пары ПД/РД и предметно
проверенных количеств. Поэтому положительный real-data сценарий и качество
сравнения пока не измерены. Preview использует только повторно подтверждённое
сервером решение текущего run; произвольный SHA из запроса не может открывать
сравнение. Результат не является выводом о нарушении.
