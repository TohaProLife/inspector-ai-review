## Что проверить

1. Загрузить разрешённый PDF и дождаться `PARTIAL` run; открыть «Кандидаты».
2. Открыть исходный лист и фрагмент; сверить строку и SHA PDF.
3. Внести основание, принять для дальнейшей проверки либо отклонить; обновить страницу и убедиться, что решение сохранилось.
4. Скачать JSON подсказок и решений. Отдельно открыть официальный протокол; при 0 findings он остаётся пустым.
5. Проверить, что findings и coverage не изменились из-за решения по кандидату.
