# Поплер: общие постраничные свидетельства v1 (28.09.2026)

`services/worker/inspector_worker/poppler_page_evidence.py` создаёт независимый от кода параметра пакет `poppler-page-evidence-v1`. Вход: исходный PDF, ожидаемые SHA-256/размер/число страниц и явно выбранный возрастающий список не более четырёх страниц. До PDF parser проверяются размер, байты и точные версии **обоих** бинарников `pdftotext` и `pdfinfo`: `25.12.0`. PDF копируется в приватный временный файл. `pdfinfo` должен подтвердить число страниц, отсутствие шифрования и отсутствие предупреждений.

Для каждого выбранного листа сохраняются `sourceSha256`, `pdfPageCount`, `pageNumber`, `providerId`, размеры в тысячных пункта, полный упорядоченный список слов (`wordIndex`, исходный текст, bbox), весь `-raw` текст, SHA исходного XML/текста, SHA списка слов и канонический `inspectionSha256`. Поля `IndependentPdfPageWords` из API совпадают по смыслу и именам; worker дополнительно даёт `wordArtifactSha256`. Хеши worker и API целиком различаются из-за разных `providerId`, сравнивать надо проверенные исходные поля и полное содержимое. Общий `contentHash` вычисляется по каноническому JSON всех страниц.

Вывод subprocess читается через selector малыми порциями, ограничение применяется **во время чтения** stdout/stderr; зависший или слишком многословный Poppler останавливается. Это защищает память до построения XML/JSON.

Пакет всегда `REVIEW_ONLY`, `absenceConclusion=NOT_AVAILABLE`, `typedFacts/findings/parameterCoverage=null`. Он не знает источник/стадию/раздел, не принимает решение о полноте перечня, не связывает строки таблицы и не утверждает значение параметра. Caller обязан отдельно проверить разрешённость корпуса и решения эксперта. Пустой текстовый лист отвергается: этот профиль не делает OCR. Ограничения: PDF 64 MiB, не более 10 000 страниц, четыре выбранных листа, XML 16 MiB и 5 000 слов на лист, результат 32 MiB. Любая неоднозначная геометрия, предупреждение Poppler или несовпадение SHA отклоняются.

Проверка: локальный `test_poppler_page_evidence.py` 6 PASS / 1 SKIP из-за Poppler 25.03/26.05 на host. Тот же набор в уже собранном изолированном образе `sha256:ed9792c21802fb44680bcf3e088f4b04f0e9490b15497a10fad971de6def5854` с Poppler 25.12 и исходным разрешённым F0152 7/7 PASS; образ запускался `--network none --read-only`, исходный PDF монтировался read-only. F0152: SHA `99ec972d7dfe5039fca922e3120bd5e486f2a26518f78044d0850992c028e7af`, 6 359 136 байт, 77 страниц; выбранные с.49/51 дали соответственно 135/173 слов, два повторных извлечения byte-identical; пакет `contentHash=074041a83a3a52c724cd8c4bf47f65cdf1ae3f0e6b66988d615496bc0a83eb26`. Это проверка извлечения и идентичности, не метрика качества и не факт по ZU-127.

Сейчас нет API save/seal/GET, release profile, durable очереди или UI для этого общего пакета. Следующий gate: API независимо повторяет полную постраничную экстракцию исходного SHA-верного PDF в закреплённом Poppler 25.12.0 и сравнивает все слова/порядок/bbox/текст; только после этого можно проектировать отдельный opt-in durable review.
