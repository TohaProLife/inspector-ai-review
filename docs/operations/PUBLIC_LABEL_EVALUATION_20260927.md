## Что можно измерить

Сейчас `precision`, `recall`, `F1` и `FPR` — **NOT_ESTIMABLE**, в машинном
отчёте `null`:

- Для двух E2E нет предсказаний на размеченном объекте и нет положительных
  выводов, которые можно сопоставить с открытыми checks.
- В выбранном файле нет отрицательных checks. Непомеченный код, помещение
  или документ нельзя объявлять `NO_VIOLATION`; unmatched prediction нельзя
  автоматически считать ложным срабатыванием.
- `ABSTAIN`, `PARTIAL`, `UNSUPPORTED` и ноль findings не входят в клетки
  TP/FP/TN/FN. Отсутствие вывода на другом объекте не создаёт FN по десяти
  тюменским положительным checks.
- Даже после запуска на тюменском объекте возможна только диагностическая
  доля найденных **10 перечисленных положительных** (или четырёх групп) при
  заранее выбранной единице и проверенной роли страницы/редакции. Это не
  recall по всем 132 параметрам или новым объектам. Для precision/FPR нужна
  независимая проверка всех предсказаний и явных отрицательных случаев.

Повторить счётчики без Docker и OCR:

```bash
python3 scripts/evaluate-public-label-availability.py \
  --output output/public-label-evaluation-20260927/report-new.json
PYTHONPATH=services/worker python3 -m unittest \
  services.worker.tests.test_public_label_availability -q
```
