# Разделы РД в ручной проверке источника

Для 47 закреплённых кандидатных правил `source_review.section_code` теперь
принимает все 27 кодов разделов, названных в пакете правил: прежние 16 кодов
и `EOM`, `GP`, `GSV`, `KJ`, `KM`, `NVK`, `OV`, `PP`, `PPR`, `SS`, `VK`.
Миграция `022_source_review_working_sections.sql` расширяет CHECK PostgreSQL;
старые решения не переписываются. UI показывает новые коды как варианты РД.

Это **только словарь**. Код раздела выбирает человек по оригинальному
документу, сохраняет основание и SHA источника. Расширение не присваивает
раздел ни одному публичному PDF, не подтверждает редакцию или пару ПД/РД,
не создаёт факт, finding или coverage. При неясном разделе остаётся `NULL`
и `ABSTAIN`.

Проверено локально: typecheck API/web/contracts; 5 профильных тестов;
PostgreSQL integration 22/22 с применением миграции 022 и повторным запуском
мигратора; `git diff --check`. Тест сверяет, что каждый раздел из закреплённой
матрицы 47 правил представлен в контракте. Синтетический API POST сохранил
`VK` для РД с `UNKNOWN` редакцией и согласованием; существующий run сохранил
прежний снимок `AR`. Реальное решение эксперта по новым кодам пока
отсутствует.
