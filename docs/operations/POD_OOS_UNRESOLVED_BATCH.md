## Область и метод

Индекс v3 содержит 203 разрешённых `TRAIN_PUBLIC / INCLUDE / PUBLIC_TRAIN`
документа и 10 142 страницы PDF; audit `PASS`. Никакие `TEST_HIDDEN` и
закрытые ответы не участвовали. Из полного текстового индекса FTS выбраны
страницы с терминами каждого кода. Для каждого кода лимит **16 страниц**,
причём сначала отбираются разные исходные PDF. Итоговые 137 адресов
«код–страница» соответствуют **110 уникальным** страницам, проверенным по
SHA артефакта, исходному SHA и индексной FTS-записи. Из 897 адресов FTS
**760 не были просмотрены по лимиту**; это не отрицательный результат.

Отдельно прочитаны исходные PDF из ZIP и сверены по размеру и SHA-256 с
manifest для всех **30 исходников**, попавших в выборку. [Квитанция](../../output/pod-oos-unresolved-20260927/source-sha-receipt.json),
SHA-256 `ce830c604b08caa5c0a27505e3403134471f0c748ce517e6483246d02e7e06b7`.
У каждого лида в отчёте указаны source ID, объект, стадия, исходный SHA,
страница, SHA артефакта, bbox, block/line и SHA текста строки. Получено
32 точных лексических якоря и 365 близких упоминаний; **лексический якорь
не означает доказанный триггер**.

Повторный запуск из checkout с доступным индексом:

```bash
uv run --offline --no-project --with pdfminer.six==20260107 python3 \
  scripts/batch-pod-oos-unresolved-public.py \
  --index /mnt/edberries-backup-disk/inspector-ai-public-document-index-v3-20260927 \
  --output /tmp/pod-oos-unresolved-repeat.json
```

Путь индекса находится на homeserver; отчёт создан с его полной локальной
копии. Путь вывода должен быть новым. Audit, manifest, strategy, catalog,
SHA страницы и соответствие FTS проверяются до записи результата.

## Внешние события и OCR

Для OOS-098–101 нет предоставленного авторизованного offline snapshot
ОСИГ, РНИС, «Мобильного КПТС» или ГРОО. Упоминания этих систем в PDF,
договоры и проектные требования не удостоверяют факт события, статус,
время и связь с машиной, рейсом, партией либо разрешением. В отчёте
`externalEventSnapshot: NOT_PROVIDED` для каждого OOS-кода.

Среди шести файлов с именами ООС в manifest отмечены **54 страницы
`OCR_REQUIRED`**. Они не считаются отсутствием параметров. Ограничение OCR
на эту пачку — восемь страниц, но **0 адресных предложений** прошли gate:
рядом с непрочитанными страницами нет специфического текстового якоря
нужной внешней системы/разрешения. Широкие слова «отходы» или «полигон»
встречаются также в несвязанных расчётах выбросов, поэтому 54 страницы
отложены до подтверждения роли листа и задачи OCR. GPU OCR не запускался.

Предметная проверка станет возможной после привязки ПОД/ООС, ППР/ТРПО и
исполнительного источника одного объекта и редакции. Для OOS дополнительно
нужен разрешённый, неизменяемый снимок внешних событий с источником и
временем. До этих gates нарушения и покрытие не выводятся.
