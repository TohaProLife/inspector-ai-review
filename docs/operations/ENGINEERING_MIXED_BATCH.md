# Пакетная проверка инженерных `OV`/`VK` источников

Отчёт [`report-v6.json`](../../output/engineering-mixed-20260927/report-v6.json)
получен на homeserver из завершённого публичного индекса v3. SHA-256 отчёта:
`d5eefd3500f0b452cdca838c9836538fd8464d05914e9de2da33d36799acc2bf`.
SHA-256 PASS-аудита индекса:
`d4d04dccbbbaa2517d5b34a0b5cb0a54dde4dcc424d9b74ec4a6f5c4313ad8cc`.
Исходный манифест закреплён SHA-256
`853225daec1888fbed19bbeb45e958154135f069799cea883dcd3c754c6c4ee7`.

Пакет читает только 203 строки `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`, и только
16 PDF одного объекта с метками `PD/OV`, `PD/VK`, `RD_ID_MIXED/OV` или
`RD_ID_MIXED/VK`. Полный индекс содержит 10 142 страницы; данный пакет
исследует выбранные разделы. Публичный файл с ответами не читается.
Каждая сохранённая строка привязана к SHA исходного PDF, номеру страницы,
SHA индексированного артефакта, индексу строки и координатам. Перед чтением
используется полный PASS-аудит, при выборке страница и FTS-строка повторно
проверяются. На странице выбираются до трёх строк: сначала точная цитата,
затем табличный кандидат и числовое измерение. Отсечённые строки учитываются.
Строка остаётся **лексическим кандидатом**, не инженерным фактом.

тематической строки не доказывает отсутствие элемента на чертеже.

`RD/VK` в выбранном объекте нет. Все 10 кодов остаются `ABSTAIN`, число
сопоставимых пар — 0, findings/coverage — `null`.

### Стадия и раздел на странице

- `F0195` p.1 и `F0196` p.1 содержат фразу «освидетельствования скрытых
  работ»: признак акта, а не основание назвать весь PDF рабочим чертежом.
- `F0201`, `F0202`, `F0204` p.1–3 содержат «РАБОЧАЯ ДОКУМЕНТАЦИЯ».
  Это адресные признаки для титульных страниц. Метка манифеста
  `RD_ID_MIXED` сохранена; стадия каждой страницы наблюдения остаётся
  неподтверждённой до связи с титулом, содержанием, листом и редакцией.
- `F0198` p.1 не дал текстового признака стадии. Название файла не
  подменяет постраничное доказательство.
- Для наблюдений 3 страницы имеют cue раздела, противоречащий метке
  манифеста, ещё 13 содержат cues обоих разделов. Это лишь повод
  проверить страницу; пересечения терминов в тексте не меняют раздел PDF.

Два показательных несопоставимых наблюдения: `F0171` p.11
(`a9070055…`, артефакт `22fe3f5e…`) упоминает радиаторы PRADO;
`F0202` p.6 (`632379a0…`, артефакт `2556d664…`) сообщает о переносе
радиатора. Общий радиатор/помещение, число секций, теплоотдача и редакция
не установлены. Для `PPM-111` `F0171` p.19 упоминает дымовые и
огнезадерживающие клапаны, но это не доказательство их расположения на
каждом пересечении. Полные SHA и координаты находятся в JSON-отчёте.

### Адресный OCR

В выбранных 16 PDF 204 страницы имеют статус `OCR_REQUIRED`. Отчёт
предлагает 9 страниц: `F0165` p.22, p.30; `F0166` p.11; `F0201` p.5,
p.7; `F0202` p.5, p.7; `F0204` p.6, p.7. Основание — соседство с
текстовым попаданием или первые страницы OCR в смешанном PDF.
OCR здесь не запускался; остальные страницы сохраняют состояние
неизвестности. Сначала проверять `F0204` p.6–7 для кодов `IOS2`/`IOS3` и
`PPM-113`, затем `F0201`/`F0202` для `IOS4` и `PPM`.

## Повторение

В изолированном checkout homeserver, где доступен индекс и образ worker:

```bash
mkdir -p /tmp/engineering-mixed-20260927
docker run --rm --network none --memory 2g --cpus 2 \
  --user "$(id -u):$(id -g)" -w /tmp \
  -v /mnt/edberries-backup-disk/inspector-ai-public-document-index-v3-20260927:/index:ro \
  -v "$PWD":/code:ro \
  -v /tmp/index-audit.json:/audit.json:ro \
  -v /tmp/engineering-mixed-20260927:/out \
  -e PYTHONPATH=/code/services/worker \
  --entrypoint python inspector-ai-homeserver-smoke-worker \
  /code/scripts/batch-engineering-mixed-public.py \
  --index /index --audit /audit.json --output /out/report-next.json
```

`/tmp/index-audit.json` должен быть копией PASS-аудита с указанным выше
SHA. Имя output должно быть новым: CLI не перезаписывает отчёты.
Проверка чистой логики:

```bash
services/worker/.venv/bin/python -m unittest \
  services/worker/tests/test_engineering_mixed_batch.py -v
```

Следующий gate: OCR только предложенных страниц с кешем по SHA PDF и номеру

составные требования каталога. До этого правила и coverage не повышать.
