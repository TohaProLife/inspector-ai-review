# ZU-127: выбор страниц по сохранённому тексту

Дата: 2026-09-28. Отдельный чистый модуль
`services/worker/inspector_worker/zu127_page_selection_v3.py` не обращается к PDF,
Poppler, OCR, сети или БД. Он принимает явные источники, снимок решений и
`document-text-v2` с SHA канонического JSON. Источник и артефакт обязаны иметь
одинаковые ID, SHA исходного PDF и число страниц; постраничное качество и
сводные счётчики проверяются повторно. Из входа исключены закрытые документы.

## Правило выбора

Сначала требуется решение по источнику: `CURRENT`, `APPROVED`, вручную
подтверждённый `sectionCode=ZU`, основание и стадия ПД. Для смешанного источника
нужно полное постраничное решение; `UNRESOLVED` не допускается. Без решения
кандидаты не ищутся: счётчики поиска остаются `null`, результат `ABSTAIN`.

На страницах `TEXT_LAYER_CANDIDATE` ищется совместное упоминание сопротивления
теплопередаче и окон либо витражей. Это только адрес листа. Глобальный лимит
выбора — четыре страницы, порядок: ID источника, затем номер страницы.
Результат сохраняет полное число и номера текстовых кандидатов, выбранные
страницы, число усечённых кандидатов и отдельно номера отложенных страниц
`OCR_REQUIRED`. Нулевые находки не дают вывода об отсутствии параметра.
`findings`, `parameterCoverage` и `typedFacts` равны `null`.

`selected_poppler_page_scope` повторно сверяет хеш результата и формирует
ровно четыре аргумента для отдельного `poppler_page_evidence`:
`expected_sha256`, `expected_byte_size`, `expected_page_count`, `page_numbers`.
Чтение исходного PDF возможно только в следующем модуле. Этот handoff не
подтверждает подлинность решения или факт сохранения текстового артефакта.
Вызывающий durable слой должен получать оба объекта из immutable run,
перепроверять release/manifest, актёра и source-review snapshot, затем
скачивать PDF по SHA. Сам `sectionCode=ZU` в публичном F0152 не утверждён:
публичный манифест относит его к `PD/OTHER`.

## Проверка

- Синтетический `document-text-v2`: 4/4 выбранных листа, 1 отложенный
  `OCR_REQUIRED`, нулевые факты; отдельные тесты бюджета сохраняют усечённые
  кандидаты одного и двух источников, общий лимит остаётся равным четырём.
- Отсутствующее/неоднозначное решение, неполное решение смешанных стадий,
  подмена SHA, дубль страницы или источника и неверное число страниц проверены.
- Текстовые выдержки исходного разрешённого F0152 с.49/51 из
  `output/singleton-unresolved-audit-20260928` обе содержат только лексические
  сигналы. Это **не** прогон по закреплённому `document-text-v2` F0152 и не
  положительное экспертное решение.
- `env PYTHONPATH=services/worker services/worker/.venv/bin/python -m unittest
  services.worker.tests.test_zu127_page_selection_v3 -v`: 9/9 PASS.

Остаётся: проверить селектор на реально сохранённом `document-text-v2` и
подключить его к аутентифицированному source snapshot, отдельной очереди,
версированному Poppler и durable save/seal/GET. До этого профиль не является
штатным правилом `ZU-127`.
