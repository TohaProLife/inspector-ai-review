# Предложения стадии и раздела с титульных страниц

`public-title-proposals-v1` читает первые 1–3 страницы каждого из 202
разрешённых PDF. Он дополняет отчёт по `sectionCandidates`: титул может
содержать «РАБОЧАЯ ДОКУМЕНТАЦИЯ» и шифр `-РД-ОВ`, даже когда индекс не
выделил строку как заголовок раздела.

Запуск требует полного аудита индекса со статусом `PASS`, точных SHA-256
открытого манифеста и версии индекса, 203 источников, 202 завершённых PDF
и 10 142 проверенных страниц. F0194 используется только как метаданные;
содержимое TXT и TEST_HIDDEN не открывается.

```bash
PYTHONPATH=services/worker python3 scripts/build-public-title-proposals.py \
  --index /path/to/public-index \
  --audit /path/to/index-audit.json \
  --output output/public-title-proposals.json \
  --pages-per-source 3 --max-proposals 800
```

Поиск ограничен буквальными фразами «РАБОЧАЯ ДОКУМЕНТАЦИЯ», «ПРОЕКТНАЯ
ДОКУМЕНТАЦИЯ», «ИСПОЛНИТЕЛЬНАЯ ДОКУМЕНТАЦИЯ» и шифрами с отдельными
обозначениями стадии и марки (`РД-ОВ`, `РД-ВК`, `РД-ВВ` и т. п.). Предложение
содержит полный исходный текст до 8192 символов, короткий фрагмент, индекс
блока/строки, bbox, ID и SHA документа, номер и SHA артефакта страницы.
Если фраза разделена строками одного блока, используется локатор блока.
Числовой индекс марки, например `РД-ОВ1` или `РД-ОВ2.1`, сохраняется в
буквальном шифре; после него не допускается слитная буква.

`ВВ` хранится отдельной маркой `VV`: точной категории открытого манифеста
для неё пока нет. `КЖ` и `КМ` могут указывать на грубую категорию `KR`, но
марку конкретного листа всё равно нужно подтвердить. При стадии
`RD_ID_MIXED` отчёт ставит `MANIFEST_STAGE_MIXED_REVIEW_REQUIRED`; даже
шифр `РД` не переводит документ автоматически в `RD`. Конфликт стадии или
категории, несколько подсказок и `OCR_REQUIRED` также отмечаются.

Лимиты: не более трёх первых страниц на PDF, 1024 строк и 512 блоков на
страницу, 1200 предложений за запуск. Обычный запуск ограничивает вывод
800 предложениями. `truncated` и счётчики пропусков показывают неполный
просмотр. Отсутствие титульной подсказки не доказывает отсутствие стадии,
раздела или параметра.

Отчёт имеет статус `REVIEW_ONLY_ABSTAIN`, не меняет манифест, индекс,
стадию, раздел, findings и coverage. Для дальнейшего использования человек
должен проверить лист, редакцию, согласование и связь с фактом.

## Адресные титульные страницы из существующего OCR-кеша

Если титул в индексе помечен `OCR_REQUIRED`, его строки можно явно
выбрать из уже готового локального OCR-кеша. Без `--ocr-selections` отчёт
остаётся прежним `public-title-proposals-v1`; с выбором создаётся
`public-title-proposals-v2` и отдельный массив `ocrProposals`.

Файл выбора — JSON-массив, максимум 16 страниц и 32 строки на страницу
(128 строк суммарно). Для каждой страницы обязательны точные ID источника,
номер одной из первых трёх страниц, индексы строк, DPI, script, ID
рендерера и провайдера. Например:

```json
[
  {
    "sourceFileId": "F0150",
    "pageNumber": 1,
    "lineIndices": [12, 13, 14, 15, 16],
    "dpi": 120,
    "script": "eslav",
    "rendererProfileId": "renderer-pdfium-5.12.1-linux-x86_64-v1",
    "providerProfileId": "ocr-paddle-3.7.0-ru-en-mobile-no-tables-v1"
  }
]
```

```bash
PYTHONPATH=services/worker python3 scripts/build-public-title-proposals.py \
  --index /path/to/public-index --audit /path/to/index-audit.json \
  --ocr-selections /path/to/selection.json \
  --ocr-cache-root /path/to/existing-ocr-cache \
  --output /path/to/title-with-ocr.json
```

Перед выводом проверяются полный `PASS` аудит, SHA манифеста и страницы,
`OCR_REQUIRED`, точное совпадение SHA исходного PDF, профилей, DPI,
content hash кеша и OCR-артефакта, границы bbox в пикселях. Кеш не
изменяется, OCR заново не запускается. `OCR_PROPOSAL` хранит отдельные
строки с исходным текстом, индексом, score и `bboxPx` в системе
`IMAGE_TOP_LEFT_PIXELS`. PDF-координаты с ними не смешиваются.
Только буквальная фраза «Раздел 1. Пояснительная записка» даёт
`sectionTitleHints: ["PZ"]`; это подсказка раздела, не подтверждённая
классификация. Даже после OCR `manifestSection: OTHER` остаётся `OTHER`.
Пустой выбор без найденной подсказки отражается счётчиком
`ocrSelectedPagesWithoutCue`, а не отрицательным результатом.

приравнивания к `ВК` отчёт не делает.
