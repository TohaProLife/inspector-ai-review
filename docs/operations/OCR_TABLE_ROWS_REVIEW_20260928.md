# Строки таблиц из сохранённого OCR: проверка F0202

`ocr_table_rows.py` извлекает пары «подпись слева — исходное значение справа»
только из уже сохранённого bounded OCR v4/v5. Требуются две явные шапки
`Наименование` и `Значение`, пересечение строк по вертикали, единственная пара,
цифра в правой ячейке и OCR score не ниже 0,8. Выход хранит точные OCR-строки,
индексы, прямоугольники, оценки, SHA страницы/рендера/источника и SHA стадии.
Числа и единицы **не нормализуются**; код параметра, редакция, стадия листа,
согласование, факт, finding и coverage не назначаются.

Offline-обёртка `scripts/probe-ocr-table-rows.py` принимает канонический
сохранённый stage и независимый отчёт о сверке источника/рендера с ожидаемыми
SHA. Она отказывает при изменении stage или неполном перечне проверенных
страниц, затем выдаёт [review packet](../../output/public-index-20260927/f0202-v5-ocr-table-review-20260928.json).
SHA-256 пакета:
`824ba9e5254ab8c37b36aa53d7081e3b79904d5f10f4941f39f4a637222fd89f`.
Пакет содержит 16 review-only пар: p.7 — 3, p.8 — 0, p.9 — 13. Ещё три
позиции не прошли порог/однозначность/шапку. Два текстовых ложных совпадения
на p.7 («Схема» → «разводкой», «Циркуляция» → «насосная») отсекаются
требованием цифры в правой ячейке.

На исходной p.7 визуально есть строка расчётного расхода тепла
`389,893 кВт (0,335 Гкал/час)`, но подпись переносится на вторую физическую
строку (`tн = −26 °C`). Консервативный геометрический разбор не включает эту
многострочную строку. Поэтому 16 предложений не означают полноту таблиц;
переносы и сомнительные OCR-оценки требуют отдельной проверки.

Тринадцать строк p.9 вручную сверены с [оригинальным публичным
листом](../../output/public-index-20260927/f0202-v5-p9-preview-20260928.png)
и исходным PDF SHA
`632379a0e541f0c81e6b03e5528946730b4433939c796db4fdc1e5c3fc8b71ee`.
Геометрические пары совпали с видимой таблицей. Ошибки OCR в латинских
буквах единиц, запятых, пробелах и римской нумерации перечислены в
[отчёте v5](BOUNDED_OCR_V5_PUBLIC_RUN_20260928.md). Ни одна строка p.9 не
соответствует точной подписи для 31 числового правила. Например, площадь и
объём **помещения ИТП** нельзя выдать за площадь и объём здания, а
`Количество этажей` не означает именно надземные этажи.

Проверки: worker unit 5/5, детерминированный повтор пакета byte-for-byte,
отказ при подмене стадии и при исключении проверенной страницы из отчёта.
Это исходный offline review aid над Compose run `CHK-C2D19963`.
Отдельный opt-in повтор `CHK-1BD8477F` сохранил те же 16 предложений и три
воздержания в новом rule stage; API независимо пересчитал их из сохранённой
OCR-стадии, а web показал для ручной проверки. Подробности, SHA и ограничения:
[сквозной протокол](OCR_TABLE_ROWS_COMPOSE_20260928.md).
