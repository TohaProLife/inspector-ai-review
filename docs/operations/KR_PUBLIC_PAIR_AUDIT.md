Первые четыре строки дают **кандидатов на текстовую пару** по типу
конструкции, этажу или отметке. Наиболее узкая пара — KR-059 для перекрытия
−2 этажа. Ни одна строка пока не устанавливает **один и тот же физический
элемент** с проверенными редакциями и утверждением. Для KR-055 также нет
проверенных документов ИД/качества фактически уложенного бетона. Поэтому
итог каждой пары — `ABSTAIN`, `comparableFacts=[]`, finding отсутствует;
покрытие параметров не повышено. Совпадение выбранных значений не доказывает
отсутствие нарушений на остальных конструкциях.

[Дополнительный просмотр листов KR-059](KR059_VISUAL_PAIR_REVIEW.md) проверил
план опалубки F0144 с. 4: на нём действительно указаны `t=250` и оси, но
ПД не даёт привязки толщины к этой зоне. Вывод `ABSTAIN` сохраняется.

## Что нужно для решения

Экспертно подтвердить применимые редакции и утверждение ПД/РД, затем
связать элемент по корпусу, этажу, осям и марке на планах. Для KR-058
сопоставить зоны толщин; для KR-055 отдельно проверить ИД и документы
качества бетона. После этого возможна предметная проверка без подмены
одного элемента похожим соседним.
