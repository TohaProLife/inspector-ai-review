# PDF, DOCX и XML сохранённых протоколов

20 октября 2026. Экспорт из сохранённой версии доступен в истории протоколов и блоке выпуска. JSON сохранён отдельно; новые кнопки скачивают PDF/DOCX/XML через текущую сессию. Повторное скачивание возвращает сохранённые байты, в том числе после новых решений или отзыва версии.

## Содержание

Отчёт следует семи разделам исходного приложения №2: состав документов, сводная статистика, отсутствие ИД, критические подтверждённые результаты, существенные подтверждённые результаты, подозрения/кандидаты, резолютивная часть. Приложения содержат последние решения инспектора по исходным листам, адреса доказательств, SHA исходников и технические пробелы. Полная история и исходный snapshot остаются внутри JSON/XML. PDF включает исходный JSON и XML как вложения; DOCX — XML как часть пакета.

Кандидаты, исходные подсказки без окончательного решения и подтверждения человека разделены. Наличие файлов не устанавливает комплектность; неизвестный ожидаемый реестр показан явно. Отсутствие ИД и неполнота проверки видны. Экспорт не добавляет нормативных предписаний, вероятностей или инженерных результатов. Исторический demo без canonical artifact получает явную учебную пометку.

## Хранение и доступ

`GET /api/protocols/:id/artifacts/{pdf|docx|xml}` проверяет READ-доступ к объекту. Для NORMAL используется только canonical artifact с совпадающими ID, SHA и числом байт. Если заявленный артефакт отсутствует или повреждён, запрос завершается ошибкой409 без подмены текущими данными. Миграция047 создаёт отдельное append-only хранилище представлений: ключ включает protocol ID, формат, template version и snapshot hash. SQL запрещает UPDATE/DELETE; конкурентные запросы возвращают первый сохранённый файл.

Заголовки `X-Content-SHA256`, `X-Protocol-Snapshot-SHA256`, `X-Protocol-Template-Version` связывают представление с версией. `X-Protocol-Validity` отражает текущий статус, файл — статус при выпуске. `private, no-store` не позволяет закешировать актуальную действительность вместе с неизменяемыми байтами. Отзыв виден в истории; скачанный ранее файл самостоятельно не обновляется.

API ограничивает snapshot8MiB, представление16MiB, таблицы10000строк, текст3000000символов и два одновременных рендера на процесс. Превышение даёт явную ошибку, успешный файл не усекается. Браузер ограничивает скачивание, проверяет MIME и при доступном WebCrypto — SHA; ошибка видна рядом с кнопками.

Шесть файлов сохранены в БД;401/404 до чтения cache, видимая409 при повреждении canonical. Overflow и неожиданных browser/HTTP ошибок нет.
