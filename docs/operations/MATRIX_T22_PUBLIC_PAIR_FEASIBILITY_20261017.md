## Следующее действие

Первым оправдан извлекатель точной высоты **ограждения территории** по F0154, с ограниченным объединением строк и независимой проверкой API. Для сравнения требуются сопоставимые PD/RD scope, сегмент/участок и одинаковая база измерения высоты. Тип/шумозащитная функция — отдельное свойство; высота сама не подтверждает замену типа.

Добавлять глобальную поддержку кода исключительно по наличию проектного текста нельзя. Пока нет второй стадии и согласованной идентичности элемента, результат остаётся извлечённым фактом/кандидатом и честным `ABSTAIN` на сравнении. Для roof и ODI сначала нужны геометрия/полнота инвентаря либо модель ограничений с областью применимости; расширение regex до любых чисел ухудшит достоверность.
