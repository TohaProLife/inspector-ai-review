# Проверка публичного индекса

`scripts/audit-public-document-index.py` читает только снимок SQLite, gzip-кеш
страниц и `document_manifest.jsonl`. Исходный ZIP и содержимое F0194 TXT не
открывает. Текст FTS для строк вне публичного allowlist тоже не читает.

Запуск внутри worker-окружения с `pdfminer.six` и `PyMuPDF`:

```bash
python3 scripts/audit-public-document-index.py \
  --manifest datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --output /data/index > /data/index-audit.json
```

Для промежуточного снимка работающего построения допустим `--allow-incomplete`.
Итог `PASS` требует точного множества разрешённых источников, завершённых PDF,
F0194 со статусом `SKIPPED_GROUND_TRUTH_TXT`, полного числа страниц и согласованных
FTS-записей. Аудит требует `page_fts_map` версии 1 и сверяет взаимно однозначные
адреса `pages` / `page_fts_map` / `page_fts.rowid`, включая отсутствие дублей,
сиротских и перепутанных ссылок. Таблица без карты считается ошибкой.
`INCOMPLETE` обозначает только недостающие или ещё обрабатываемые
источники без ошибок целостности. `FAILED` означает сбой источника либо ошибку
схемы, метаданных, страницы, SHA, качества, provenance или FTS. Код выхода 0
возвращается только для `PASS`, либо для `INCOMPLETE` с явным флагом.

Отчёт JSON содержит ожидаемые и текущие счётчики (`indexedPages`, `ftsRows`,
`ftsMapRows`), категории качества и парсера,
кандидаты таблиц и разделов, агрегаты по объекту/стадии/файлу, коды ошибок.
Список ошибок ограничен `--max-errors`, полный счётчик остаётся в `findingCount`.
Проверка ограничивает память одним распакованным артефактом до 64 MiB плюс карты
SHA для страниц; она не доказывает правильность распознанных инженерных фактов.
