# Отдельное решение о применимости OCR-строки

Реализация хранит ручное решение отдельно от транскрипции, факта и
сравнения. Миграция 023 создаёт append-only журнал с внешними ключами к
снимкам транскрипции и решения по источнику конкретного run. API принимает
`APPLICABLE`, `NOT_APPLICABLE` или `UNSURE` с кодом, атрибутом, стадией,
ключом объекта, контекстом и основанием. При записи и чтении он повторно
проверяет исходные OCR/rule артефакты, PDF и рендер SHA, строку, оба снимка,
их хеши, раздел и стадию страницы. Положительное решение требует
подтверждённой транскрипции и актуального утверждённого источника.

24 skipped; web 33 passed; worker 648 passed; сборка API/web прошла.

снимка и отсутствие findings/coverage. Тест не является экспертным решением
по реальному PDF.
