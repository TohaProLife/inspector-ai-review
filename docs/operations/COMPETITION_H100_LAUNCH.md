# Запуск конкурсного профиля H100: актуальная инструкция

На 20 октября 2026 используйте [H100 V9: подготовка и запуск](H100_READINESS_20261020.md) и [квитанцию локальной приёмки](H100_V9_ACCEPTANCE_20261020.md).

В новом Git source ZIP команды выполняются из корня архива, где лежит `package.json`; в прежнем V9 review ZIP — из `source/`. [Текущий порядок передачи](FINAL_HANDOFF_20261020.md). Инструкция V9 содержит подготовку env без смены существующих секретов, выбор выделенного GPU, аппаратный preflight, четыре Compose-файла, запуск и проверки provider inference. Для отдельного полного source audit V4 дополнительно используйте последний ресурсный overlay из [инструкции V4](full-source-audit-v4-v1.md).

Прежние команды на этой странице относились к V6. Один `stack.sh server up` подключает только base+server и не включает актуальные matrix-v13/h100-feedback overlays. Для V9 используйте `infra/h100-readiness.py`; старый `check-competition-profile.py` предназначен для V6. Не переносите старые selectors поверх env V9.

Без H100 можно проверить реальное разрешение Compose командой `python3 scripts/check-h100-offline-compose.py`. Она не запускает контейнеры и не подтверждает CUDA. Локально приняты исходники, переносимые тесты и установленные CPU-контейнеры API/worker/web; аппаратная приёмка H100 остаётся открытой.
