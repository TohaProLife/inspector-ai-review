Один физический лист может одновременно содержать РД-штамп и исполнительную
отметку. Эти строки не разрешают использовать весь лист как единую стадию
в сравнении. Для перехода к фактам нужны проверка ревизии/утверждения,
область факта на листе и связь с тем же физическим элементом в другом
документе. До этого все четыре остаются `ABSTAIN_MIXED_STAGE_SAME_PAGE`.

В текущей форме проверки источника одна страница получает только одну
метку стадии. Для таких четырёх листов инспектор должен указать
`1=UNRESOLVED` и приложить основание: downstream сравнение этой страницы
тогда воздерживается. Подсказка в форме уточнена по результату этой
проверки. Для использования отдельных фактов РД и ИД с одного листа
понадобится разметка **областей фактов** с отдельным происхождением и
подтверждённой редакцией.

## Пакет локаторов для проверки источников

[Экстрактор](../../services/worker/inspector_worker/mixed_stage_region_proposals.py)
строит отдельные review-only подсказки `RD_TITLE_MARK` и `EXECUTION_MARK`
из OCR-строк, если найден ровно один шифр `-РД-`, один знак стадии `РД`,
одна надпись `ИСПОЛНИТЕЛЬНЫЙ`, а надпись исполнительной отметки находится
левее знака стадии. Он проверяет SHA каждого входного отчёта, закреплённый
SHA открытого manifest, профиль/регион/cache key и контентный хеш OCR;
каждый локатор сохраняет строку, координаты crop, score, SHA рендера и
OCR-артефакта. Пересечение или недостаток знаков возвращает пустые подсказки.

[Пакет четырёх источников](../../output/public-index-20260927/mixed-stage-region-proposals-20260927.json)
содержит по две пространственно раздельные подсказки для 4/4 PDF, статус
каждого `REVIEW_ONLY_ABSTAIN`, `findingCount=null`, `parameterCoverage=null`.
SHA-256 пакета:
`a48ec9e5de3f172295582241d6c3f6bc61a01fa99de5bd73c13e5a0e73c01092`.
В тестах экстрактора 4/4 проверены позитивный случай, пересечение областей,
подмена SHA/стадии/скрытый документ и чтение закреплённых отчётов.
Тот же builder отдельно выполнен внутри worker-образа изолированного
homeserver на четырёх исходных OCR JSON; SHA-256 результата совпал с
локальным `a48ec9e5de3f172295582241d6c3f6bc61a01fa99de5bd73c13e5a0e73c01092`.
