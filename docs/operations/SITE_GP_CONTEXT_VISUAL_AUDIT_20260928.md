Оригинальный PDF позволяет получить координаты строк и колонок, но
сохранённый `document-text-v2` сейчас содержит только bbox текстового
**блока**. По нему нельзя независимо доказать, что подпись и толщина
на p.20 находятся в одной строке. До появления отдельной неизменяемой
геометрии строк допустимы лишь раздельные локаторы ячеек с пометкой
`ROW_ASSOCIATION_UNVERIFIED` для ручной проверки; количество МАФ на p.21
остаётся неизвестным. Для `SPZU-036` возможен кандидат отрывка текста.
Никакой из этих контекстов не стал подтверждённым фактом, сравнением или
finding. F0155 — отдельно зарегистрированный файл с изменениями по
замечаниям; из названия нельзя вывести, какая редакция утверждена.

Текущий профиль `SITE_GP_CONTEXT_TEXT` показывает только точные
лексические локаторы для `SPZU-029/032/033/035/036` и в каждом случае
воздерживается. Предметные значения и геометрические связи требуют
отдельного извлекателя, проверки исходного листа и решения эксперта.
