`TEXT_LAYER_CANDIDATE`, хотя текст содержал 49 621 литеральную заглушку

`OCR_REQUIRED` с причиной `TEXT_DECODING_ANOMALY`. Историческая v1 явно
поддерживается только для воспроизведения уже закреплённых выпусков;
ключ durable-кеша и проверка результата учитывают версию политики.

## Граница результата

Индекс и лексические прогоны проверены на оригинальных открытых PDF.
Исполняемое сопоставление всех 47 кодов пока невозможно без подтверждения
стадии, раздела, редакции, согласования, сущности и совместимости величин.
Поэтому система воздерживается от findings и не заявляет coverage. Сквозной
прогон изолированного Compose после v4 изменения приведён ниже.
