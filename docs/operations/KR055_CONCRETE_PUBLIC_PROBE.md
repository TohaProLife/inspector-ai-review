# KR-055: класс бетона на открытых листах КР

## Граница

Автономная проба читает только четыре исходных PDF из пакета участника после
проверки `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`, объекта, стадии, раздела КР,
размера, закреплённого SHA-256 и числа страниц. Не читает экспертные ответы,
не подключена к normal-run или durable release. Результат всегда
`CLARIFICATION_REQUIRED/ABSTAIN`, `comparableFacts=[]`, `finding=null`.

Проба привязывает **напечатанный класс** к подписи элемента в пределах листа.
ПД и РД пока не признаны утверждёнными актуальными редакциями, а конструкции
между комплектами не сопоставлены до уровня корпуса, зоны и элемента. Класс
исполненного бетона и документы контроля качества также не проверены.

## Проверенные источники

| Файл | Стадия | PDF-страницы | SHA-256 |
| --- | --- | --- | --- |
| F0106 | ПД/КР | 49–50 | `ae8b16439650526a5ef6e1975c852fa38c2ab4466cd73ab725a47bcb32a6b655` |
| F0139 | РД/КР | 4 | `d59c225e75d1e0227f08869b31165bd93bf85ed4b1da005c3e86ebc27023b73f` |
| F0140 | РД/КР | 27 | `2c46f909396f33e4286637319fe4829d8d4cf6742c0e7337577dfdc4127ab085` |
| F0141 | РД/КР | 4 | `421a34429325f424d3e29086810b1283e805d9bb3c75646508e5434b248e5d5f` |

F0106 содержит отдельные строки корпусов К1 и К2 о фундаментной плите
`B40` и вертикальных конструкциях `В60`; на с. 50 — строки подземной части
и лестниц `В30`. В F0140 с. 27 спецификация фундаментной плиты на отметке
−13,750 содержит `B40,F150,W6`. F0141 с. 4 прямо указывает `В60` для стен.
F0139 с. 4 прямо указывает `В30` для лестничных маршей и площадок. Похожая
строка `B40` на F0140 с. 3 не используется: текст многоколоночного листа
не даёт надёжной привязки этой строки к фундаментной плите.

Каждое наблюдение содержит исходный текст, нормализованный класс `B30/B40/B60`,
подпись элемента и две рамки в PDF points с началом координат слева сверху,
физическую страницу, индекс строки текстового слоя, SHA-256 и стадию источника.
Наличие одинакового класса в ПД и РД само по себе не доказывает отсутствие
нарушений KR-055 по всему объекту.

## Запуск

```bash
PYTHONPATH=services/worker python3 scripts/probe-kr055-concrete-public.py \
  --manifest datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --f0106 /path/to/F0106_raw.pdf \
  --f0139 /path/to/F0139_raw.pdf \
  --f0140 /path/to/F0140_raw.pdf \
  --f0141 /path/to/F0141_raw.pdf \
  --output /path/to/kr055-report.json
```

Нужны PyMuPDF и Python worker. Тесты:

```bash
PYTHONPATH=services/worker python3 -m unittest \
  services/worker/tests/test_kr055_concrete_observations.py -v
```

## Фактическая проба на homeserver, 27.09.2026

F0139 и F0141 извлечены из исходного ZIP пакета участника по путям открытого
manifest; F0106 и F0140 взяты из уже сверенных копий. Для всех четырёх
проба повторно проверила размер, SHA-256 и число страниц **перед** чтением
текстового слоя. Выполнена отдельным контейнером worker без обращения к API,
очереди и закрытой разметке.

[Отчёт](../../output/kr055-concrete-public-20260927/report.json): 11
наблюдений — 8 ПД и 3 РД; 11 уникальных локаторов; классы `B30`, `B40`,
`B60`; `ABSTAIN`; 0 findings. SHA-256 файла отчёта после копирования:
`5828201292844e055834f8c4b0a86ad612d8080d693005b146c331a1807b7f3e`.
Внутренний `contentHash` пересчитан локально:
`446914a29d25031b8fed2d67b988bcf8c19b44fd07624022d841eae7e56ad1f9`.
Четыре адресных теста прошли: нормальный срез, подменённый/скрытый источник,
неверный класс или элемент, дублирование и отсутствие текста.

## Для предметного решения

Подтвердить применимые редакции и утверждение комплектов; связать фундамент
по корпусу/отметке/зоне, стены по этажу и корпусу, лестницы по марке; затем
проверить ИД и документы качества бетона. До этого KR-055 не включён в
поддерживаемое покрытие и не выдаёт положительный либо отрицательный verdict.
