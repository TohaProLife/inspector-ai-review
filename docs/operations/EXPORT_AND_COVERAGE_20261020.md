## Приёмка экспорта

Исходное ТЗ: раздел9.2 и приложение№2; PDF/DOCX/XML в дашборде имеют приоритет Medium. Протокол отражает сохранённую версию: живые findings не подменяют её при скачивании. Кандидаты, подтверждённые результаты, решения инспектора и unsupported показываются раздельно. Неизвестный ожидаемый состав документов не становится полной комплектностью. Фиксация версии не объявляется УКЭП или внешней доставкой в ИАИС.

Рендер выполняется локально в API без GPU, браузера, облачных сервисов и внешних шрифтов. Шрифты и renderer versions входят в поставку. Содержимое исходного JSON доступно отдельно. Технические ограничения экспорта завершаются явной ошибкой, а не усечённым успешным документом.
