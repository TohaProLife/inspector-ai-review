# OCR-таблицы v3 на публичном F0202

Отдельный opt-in профиль `conservative-ocr-table-rows-v3` связывает короткое
продолжение подписи с соседней строкой значения. V1 и v2 сохранены без
изменения. Каждая часть подписи остаётся отдельной OCR-строкой с индексом,
рамкой и оценкой; API заново выводит пакет из сохранённой OCR-стадии и
отвергает подмену строки, геометрии, оценки или SHA. Это предложения для
ручной проверки, без назначения кода и без утверждения факта.
