# SITE_GP_CONTEXT_TEXT: пять кодов ПЗУ

28 сентября 2026. Добавлен независимый opt-in профиль
`typed-pz002-pz017-site-gp-context-review-v1` для `SPZU-029`, `SPZU-032`,
`SPZU-033`, `SPZU-035`, `SPZU-036`. Он показывает точные строки сохранённого
текстового слоя как навигацию для эксперта. Каждый код остаётся `ABSTAIN`;
`findingCount` и `parameterCoverage` равны `null`.

Вход допускается только при immutable решении `CURRENT`/`APPROVED` об
источнике ПД/ГП и совпадении SHA исходного PDF, committed
`document-text-v2`, страницы, блока и строки. Worker ограничивает число
лидов, помечает усечение и возвращает отдельную предметную причину
воздержания по каждому коду. API независимо пересчитывает строки, причины,
счётчики и SHA при save/seal/GET; web показывает локаторы и ссылку на
проверенный исходный PDF. Старые release профили остаются отдельными.

Оригинальные разрешённые PDF `F0126` и `F0154` сверены с публичным
manifest и индексом v4; пять листов повторно отрисованы PDFium 5.13.0 и
[проверены визуально](SITE_GP_CONTEXT_VISUAL_AUDIT_20260928.md).
Заголовок дорожных конструкций, ведомость МАФ, текст о рельефе, подписи
охранных зон и отрывок об ограждении служат только контекстом. Особо:
наличие файла F0155 с изменениями по замечаниям не позволяет назначить
F0154 актуальной утверждённой редакцией. В реальном корпусе для этих
источников положительного решения эксперта нет.

Синтетический пакет Python с пятью лидами принят независимым API
валидатором; его тесты отвергли подмены и ложное отсутствие лида.
Локальный полный `npm run check` после интеграции: API 282 pass/34 skip,
web 64 pass, Python worker 713 pass, сборка PASS. Последовательный
PostgreSQL suite: 11 файлов, 35 тестов, exit 0, включая новый профиль и
подмены сохранённых артефактов. Сквозной [isolated Compose на F0126](SITE_GP_CONTEXT_COMPOSE_20260928.md)
прошёл: 9/9 jobs, пять `ABSTAIN`, ноль лидов без экспертного решения.
Это доказывает безопасное воздержание, а не качество извлечения значений.
