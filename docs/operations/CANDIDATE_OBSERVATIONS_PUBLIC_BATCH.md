# Наблюдения 47 кодов на публичном корпусе

Проверка: 202 разрешённых PDF из пакета участника, 10 142 страницы. Ещё один
публичный TXT входит в инвентарь 203 документов, но его содержимое не читали.
Проверены manifest SHA каждого источника, SHA постраничного индекса и
согласованность текста с FTS. Использованы только `TRAIN_PUBLIC`, `INCLUDE`,
`PUBLIC_TRAIN`.

## Воспроизведение

Скрипт: [`batch-candidate-observations-public.py`](../../scripts/batch-candidate-observations-public.py).
Нужны готовый индекс v3, пакет участника и Python-зависимости worker. Пример
на homeserver после синхронизации этой версии кода:

```bash
services/worker/.venv/bin/python scripts/batch-candidate-observations-public.py \
  --index /mnt/edberries-backup-disk/inspector-ai-public-document-index-v3-20260927 \
  --output output/candidate-observations-public-20260927/report.json
```

Для запуска нужен Python с зависимостями worker: готовый virtualenv в примере
существует в локальном checkout, на homeserver его нужно создать отдельно.
Скрипт не перезаписывает существующий отчёт. Текущий
[`report.json`](../../output/candidate-observations-public-20260927/report.json)
имеет SHA-256 `550536e0538a38464336c31c3455a2d845b13f8e87e24bc47df201be24c4e8fa`.
Проверка локально по копии неизменённого индекса заняла около 17 секунд.

## Результат

| Проверка | Результат |
| --- | ---: |
| Документы из разрешённого манифеста | 203 |
| PDF с проверенными страницами | 202 |
| Проверенные страницы | 10 142 |
| Пригодные страницы текстового слоя | 8 668 |
| Страницы с необходимым OCR | 1 474 |
| Коды и семейства | 47 / 9 |
| Наблюдения на уровне run | 0 |
| Типизированные факты из этих наблюдений | 0 |
| Вывод о находках и покрытии | `null` / `null` |

Для прошедших source-review gates извлекатель умеет создать типизированное
предложение по 31 числовому и восьми классовым кодам. Классовый факт хранит
буквальный токен; порядок классов задаётся только отдельно проверенной
шкалой. Восьми кодам состава нужен доказанный полный набор элементов,
поэтому одно найденное слово остаётся наблюдением без typed fact.
Синтетические проверки дали 39 typed fact предложений из 47 адресных строк;
это тест контракта, не результат открытого корпуса.

Причина ABSTAIN одинакова для всех семейств: пакет участника не содержит
подтверждённых статусов текущей ревизии и утверждения источника. Для всех 202
PDF сохранены `revisionStatus=UNKNOWN`, `approvalStatus=UNKNOWN` и
`sectionCode=null`; смешанные RD/ID страницы остаются `UNRESOLVED`. Поэтому
страницы не допущены в run preview. Отчёт не утверждает отсутствие меток:
`NO_EXACT_LABEL_LEAD` при нуле просмотренных страниц не выводится.

Независимая ранее выполненная проверка индекса нашла **5 точных строк меток**
и **45 близких строк** среди семейств. Это подсказки для навигации, не факты.
Отдельный [адресный OCR triage](UNRESOLVED_TARGETED_OCR.md) нашёл **60
лексических совпадений на 19 страницах** для четырёх кодов из 47; 51 требуют
подтверждения раздела, 9 не соответствуют роли стадии. Эти совпадения не
увеличивают число наблюдений или покрытие. Отчёт хранит SHA обоих независимых
источников сигналов.

## Что проверить

- Подтвердить для конкретных PDF текущую ревизию, утверждение и обозначение раздела на чертеже; сохранить решение с привязкой к SHA источника.
- Для смешанных RD/ID файлов подтвердить роль нужной страницы.
- Повторить preview и извлечение наблюдений на проверенных источниках, затем вручную связать одинаковый объект, элемент и единицу измерения до сравнения.
