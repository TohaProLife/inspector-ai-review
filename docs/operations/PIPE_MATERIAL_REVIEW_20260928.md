# Материал труб ИОС2/ИОС3: публичный проверочный срез

`IOS2-072` требует материал и класс давления **конкретной напорной ветви В1/Т3**; `IOS3-075` требует материал и тип **конкретной канализационной ветви**. Одна лексема «труба», материал соседней системы либо марка без идентичности ветви не дают факта для правила. Проверка остаётся `REVIEW_ONLY_ABSTAIN`.

Модуль [`pipe_material_review.py`](../../services/worker/inspector_worker/pipe_material_review.py) читает только восемь разрешённых `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN` PDF объекта `OBJ-TYUMENSKAYA-5-GOLD-SEED`: F0163–F0169 с меткой манифеста `PD/VK` и F0204 с `RD_ID_MIXED/VK`. Для каждого исходного PDF поток из `01_ПАКЕТ_УЧАСТНИКАМ_3_ОБЪЕКТА.zip` проверен по размеру и SHA-256 манифеста. Перед обходом проверены SHA манифеста `853225da…`, PASS-аудита индекса v4 `69ef56fc…`, версия `7d7dfa2f3e0279a91095`; каждая страница сверена по SHA индексированного артефакта. Закрытые ответы и `TEST_HIDDEN` не читались.

Детерминированный срез охватил **293 страницы** восьми PDF: 195 с кандидатным текстовым слоем, **98 `OCR_REQUIRED`**. Из текстового слоя получены 28 строк на 13 страницах: 31 буквальное упоминание материала, 5 сетей, 3 признака типа трубы, **0 буквальных классов давления**. Лишь пять строк содержат на одной строке и явную сеть, и материал: 1 подсказка `IOS2-072`, 4 подсказки `IOS3-075`. Ещё 23 строки остаются без кодовой подсказки; это не отрицание параметра на листе. 0 строк прошли как индексные `tableRowCandidates`. Например, на F0167 p.6 таблица видна человеку, однако структурный индекс не классифицировал её строки как кандидаты таблицы. Пропущенных строк из-за неверного локатора в выбранном срезе — 0.

[Машинный отчёт](../../output/pipe-material-review-20260928/report.json), SHA-256 `47cadc17d776b7df4b3832345108a71842a3cb3c29de0306238882027bcfff2b`. В каждой записи сохранены полный SHA PDF, страница, SHA артефакта, адрес блока/строки, координаты, SHA исходной строки и **раздельные** буквальные поля `rawNetwork`, `rawMaterial`, `rawPressureClass`, `rawPipeType`. `sameLineCodeHints` — подсказка для просмотра, не присвоение кода факту. Никаких сопоставимых пар, фактов, findings и coverage отчёт не содержит.

## Адресный OCR F0204 p.6

Публичный OCR-кеш для этой страницы уже существовал. Через `cached_public_ocr_page` повторно открыт **оригинальный** PDF из ZIP; контейнеру задан `--network none`, поэтому provider вызвать невозможно. Результат — `HIT`, 287 строк, исходный PDF SHA `6b15a5de…`, ключ кеша `fed4fe81…`, SHA файла кеша `cd4b0010…`, OCR artifact hash `1a3ca99e…`. [Receipt повтора](../../output/pipe-material-review-20260928/F0204-p6-cache-hit-receipt.json), SHA `3893d6dfd955d2b0fbb7ea43a9e8e78724873d372cf0d8a8744a8e2ae0e2f17c`; [сам кеш](../../output/pipe-material-review-20260928/F0204-p6-ocr-cache.json) хранит полные строки и координаты. Это тот же профиль PDFium 90 DPI, `eslav`, PaddleOCR 3.7.0, что в прежней пачке; ключ включает SHA PDF, страницу, DPI и версии профилей.

Независимый повторный рендер PDFium из исходного ZIP дал [PNG 2980×2105](../../output/pipe-material-review-20260928/F0204-p6-pdfium90.png) с SHA `4ee8449a25a036c2c79ed0ada650b471492da51fce27a03dd56c5ca81216f0d3`, совпадающий с полем рендера в OCR-артефакте. Новый [проверяемый review-пакет](../../output/pipe-material-review-20260928/F0204-p6-ocr-review.json), SHA `1f49e7178e19ea7e82ac6e99aedcd501b21b785e4d04df9d3a048307d7c2e520`, имеет четыре строки с буквальным или испорченным OCR-токеном материала: № 44, 48, 124, 126. `evaluate_cached_pipe_ocr` независимо пересчитывает SHA receipt/кеша/PNG, canonical hash кеша и артефакта, проверяет номер страницы, профиль и координаты; кодовых подсказок, фактов и пар не создаёт.

Визуальная сверка этих четырёх адресов на оригинальном листе:

- № 44: OCR `изнапорных НПВХ0`, на изображении раздельные слова «из напорных НПВХ Ø 110–200 мм». Контекст — **К2, водосток**, а не доказанная ветвь В1/Т3.
- № 48: OCR читает `0.оО` для отметки `0.00`; материал НПВХ возле описания стояков К2 виден. Сеть и материал стоят на разных строках.
- № 124: OCR `0 50-10мм`, на изображении `Ø 50–110 мм`; рядом описание напорных НПВХ в зоне **К4, дренажных стоков**. Размер OCR неверен.
- № 126: OCR `прубы стальной`, на изображении `трубы стальной` для напорного трубопровода от насосов. Привязка к конкретной ПД-ветви не доказана.

Ни одна из этих строк не содержит числовой класс давления или проверенный одинаковый элемент ПД/РД. Для `IOS2-072` сеть на листе не подтверждает В1/Т3; для `IOS3-075` нельзя автоматически приравнять К2/К4 к требуемой канализационной ветви. F0204 остаётся `RD_ID_MIXED` без утверждённой редакции. Итог: `ABSTAIN`, `facts=[]`, `comparablePairs=[]`, findings/coverage `null`.

## Полная адресная OCR-очередь для остальных 97 страниц

[Очередь](../../output/pipe-material-review-20260928/ocr-queue-v1.json), SHA-256 `d4639c9427a50ae12180aec756ddd0a4238c12fb308dcce5bd0774f391c605da`, состоит ровно из оставшихся 97 `OCR_REQUIRED` страниц F0163 (2), F0165 (18), F0166 (15), F0204 (62). Каждая привязана к SHA оригинального PDF и SHA страничного артефакта аудированного индекса v4.
