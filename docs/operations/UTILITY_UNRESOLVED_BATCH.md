# Пакетная проверка оставшихся неразрешённых ИОС/ППМ/ОДИ/ЗУ

В этой пачке 21 код из [стратегии 80 неразрешённых параметров](../../output/unresolved-parameter-strategy-20260927/report.json): `IOS1` (3), `IOS5` (1), `PPM` (9), `ODI` (5), `ZU` (3). Границы определений проверены по исходному каталогу 132 параметров и реестру семейств. Все эти коды имеют `DESIGN_ONLY` и не имеют подтверждённой сопоставимой пары документов.

Скрипт [batch-utility-unresolved-public.py](../../scripts/batch-utility-unresolved-public.py) повторно использует уже построенный индекс 203 разрешённых документов `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`. Он проверяет SHA манифеста, полного PASS-аудита, отчёта стратегии и каждого прочитанного артефакта страницы. ZIP/PDF не распаковывает и OCR не запускает. Узкие выражения дают только адресные строки для проверки; кандидатом таблицы считается строка, чьи текст, адрес и прямоугольник точно совпали с индексированной строкой внутри страницы.

Каждая строка отчёта несёт исходный путь, SHA PDF, объект, стадию и раздел из манифеста, статус редакции `UNVERIFIED`, страницу, SHA артефакта и координаты PDF. Код и семейство остаются `ABSTAIN`. `findingCount` и `parameterCoverage` равны `null`. Совпадение текста не подтверждает идентичность элемента, версию, единицу измерения, определение величины или применимость нормы. `OCR_REQUIRED` означает неизвестное содержимое, а не отсутствие параметра.

## Запуск на homeserver

Скрипт и модуль запускаются в отдельном временном каталоге; полный публичный индекс читается без изменения:

```bash
python3 /tmp/utility-unresolved-20260927-run/scripts/batch-utility-unresolved-public.py \
  --manifest /home/freetok/Projects/inspector-ai-homeserver-smoke/datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --index-root /mnt/edberries-backup-disk/inspector-ai-public-document-index-v3-20260927 \
  --audit /tmp/utility-unresolved-20260927-run/index-audit.json \
  --strategy-report /tmp/utility-unresolved-20260927-run/strategy-report.json \
  --catalog /home/freetok/Projects/inspector-ai-homeserver-smoke/services/worker/rules/parameter_catalog_132.jsonl \
  --registry /home/freetok/Projects/inspector-ai-homeserver-smoke/services/worker/rules/parameter-family-registry-v1.json \
  --output /tmp/utility-unresolved-20260927-run/report.json
```

Вывод ограничен 500 адресными строками на код и 20 адресными OCR-страницами на семейство; полный счёт совпадений сохраняется, а поля `leadsTruncated` и `queueTruncated` явно показывают усечение. OCR-план не меняет этап или раздел источника. Источники `RD_ID_MIXED` остаются со статусом стадии `MIXED_STAGE_UNRESOLVED`.
