# PZ-010: наблюдение из публичного индекса F0101

`pz010_index_observations.py` читает только разрешённый `TRAIN_PUBLIC/INCLUDE`
источник F0101 (`OBJ-NOVOSLOBODSKAYA`, ПД). Манифест помечает его раздел как
`OTHER`, поэтому раздел ПЗ подтверждается отдельно титульным листом PDF p.1:
`ПРОЕКТНАЯ ДОКУМЕНТАЦИЯ`, `Раздел 1`, `Часть 2 «Пояснительная записка»`,
`НВС-2025/03-ПЗ`. Все четыре маркера должны быть единственными на странице.

На PDF p.10 исходный text layer хранит строку таблицы в отдельных блоках:
`Количество квартир, в т.ч.:`, `кв.`, заголовок колонки `Всего:` и `92`.
Проверяется **вся** страница из индекса, а не только четыре найденных блока:
метка, единица, колонка и целочисленное значение должны давать одну
геометрически согласованную пару. Локаторы сохраняют исходные номера блоков и
координаты `PDF_BOTTOM_LEFT_MILLI_POINTS`.

Вход сверяется с публичным манифестом SHA-256
`853225daec1888fbed19bbeb45e958154135f069799cea883dcd3c754c6c4ee7`
и записью F0101 SHA-256
`01db90e015c39a9502b99969ce04f27825265203bc8728da6141d7b6d2b1ef54`.
Оригинал F0101 дополнительно прочитан напрямую из публичного ZIP на homeserver:
891 618 байт, тот же SHA-256, 13 страниц. Индекс проверяет завершённость всех
страниц источника, версию извлечения,
статус text layer и SHA-256 сжатых артефактов выбранных листов. Повторное
чтение всей страницы сверяется с тем же SHA. Чтение оригинального PDF во время
этого probe не требуется; хеш источника взят из манифеста и проверенного
постраничного индекса.

## Проверенный результат

На read-only копии индекса, а затем непосредственно на homeserver 2026-09-27
наблюдение вернуло одно
значение `92` с единицей `кв.`. Артефакты p.1 и p.10 имеют SHA-256
`1f03ca3520c94c93e66380737116fbdfeb207b3b71b66741c259f35d83e41092`
и `241117a27201f6c9a50cb8fe802f5df23ae0336f50a3b82069e5fe3f20f5605e`.
Хеш отчёта: `310cdbb999164fc988141cb7becf83447c75e6f0841a9c33c1445223c123bd2c`.
Повторный Docker-прогон сохранил [JSON-отчёт](../../output/public-index-20260927/pz010-index-observation.json)
с SHA-256 файла `d083637634d2b4c32dec67a0d4beb28e6df3820fa97067dcb0432fe8ab599c18`.
Публичный аудит всего индекса ранее завершился `PASS`: 203 разрешённых файла,
10 142 страницы PDF, 0 ошибок целостности.

Выход остаётся `ABSTAIN` / `CLARIFICATION_REQUIRED`, `finding: null`:
актуальность и утверждение ПД не подтверждены, разрешённой пары РД АР нет,
связь редакций неизвестна. Значение не увеличивает rule coverage и не означает
отсутствия нарушения.

## Запуск

В окружении worker с `pdfminer.six==20260107` (версия публичного индекса):

```bash
PYTHONPATH=services/worker python3 -m inspector_worker.pz010_index_observations \
  --manifest datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --index /path/to/verified/public-index
```

Проверка адаптера:

```bash
PYTHONPATH=services/worker python3 -m unittest services.worker.tests.test_pz010_index_observations -v
```

Проверить вручную p.1 и p.10 в viewer, затем решить принадлежность значения
конкретному объекту и применимой редакции. Автоматическое сравнение с РД
включать только после независимого подтверждения источника и связи документов.
