# T60: полные исходные строки и явная потеря геометрии

18 октября 2026. Принята основа `document-text-v3`; на стенд пока не установлена.

Новый artifact сохраняет исходный текст строки вместе с LF, путь в native layout и точные native координаты. Строки с пригодной рамкой находятся в `locatedLines`. Нулевые native строки и положительный микротекст, схлопнувшийся при переводе в milli-point, сохраняются в `unlocatedLines` с проверяемой причиной. Рамки не увеличиваются искусственно. Геометрия считается точной десятичной арифметикой с округлением half-even.

JSON Schema — канонический контракт. DTO генерируются из него; независимые Python/TS readers проверяют весь artifact, профиль извлечения, геометрию, порядок и уникальность путей, quality и полный content hash. Quality обозначает техническую пригодность text layer, не вероятность правильности или полноту анализа. Старые потребители v2 продолжают отвергать v3. SHA профиля сам по себе не подтверждает разрешённый серверный release.

Проверено: 61 TS-тест, 25 Python methods, 26 соседних тестов; 40 полных общих reader cases; 11 исходных PDF/14 страниц с полными ожидаемыми результатами и 2 отрицательных оригинала. Включены четыре поворота, CropBox, смещённое начало координат, микротекст, смешанная некорректная геометрия, native callbacks и точные границы ресурсов. API typecheck/build прошли. Изолированно установленный wheel воспроизвёл семь полных оригинальных результатов и два ожидаемых отказа; wheel/sdist сохранили все 22 rule resources.

Первоначальные RED и исправление ошибочного имени тестового helper сохранены. Исправлены различие причин при превышении 512 страниц и `RecursionError` на глубокой структуре PDF. Ни один исходный контрольный результат не подгонялся под код.

Полный реальный F0161 по-прежнему не создаёт v3 artifact: на странице 13 есть видимый текст внутри Form, для которого стандартный pdfminer layout не создаёт `LTTextLine`. Сохранён `UNSUPPORTED_TEXT_LAYOUT`, native ancestry и выбранный PDF-render. Это ограничение следующего этапа, не успешная обработка реального документа. Подстановка `all_texts=True` в отдельном диагностическом опыте дала настоящую строку pdfminer `10\n` с более глубоким native path; текущий режим не изменён.

Зафиксировано 859 файлов. Из прежних 828 изменён только разрешённый type-only export в contracts index; 827 остальных и две внешние зависимости сохранены. Runtime, coverage 59/67/73, qualified pairs 0 и probability null не изменились. Browser pending по существующему security hold; статический PDF-render и HTTP не заменяют браузерную проверку.

Доказательства: `output/matrix-t60-20261018/acceptance.json`, `source-freeze.json`, `qa-final-receipt.json`, `root-installed-package-result.json`, `root-form-render-diagnostic.json`.

Без паузы T61: отдельный явно выбранный профиль анализа вложенных Form с полным native path и прежним поведением стандартного профиля. После него — durable release/cache/header/admission, PostgreSQL и исходный текст в UI, затем направленное сравнение светильников ZU-130.
