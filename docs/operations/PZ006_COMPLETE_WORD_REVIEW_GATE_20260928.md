# PZ-006: полная независимая проверка слов на F0101, страница 9

Исходник: разрешённый `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN` F0101, SHA-256
`01db90e015c39a9502b99969ce04f27825265203bc8728da6141d7b6d2b1ef54`,
891 618 байт, 13 PDF-страниц; manifest: `PD/OTHER`. Оригинал для локальной
проверки: `/tmp/inspector-pz006-F0101-public.pdf`. Код параметра остаётся
предметно конфликтным: название каталога указывает надземный объём, триггер —
количество этажей. Раздел `OTHER` не повышался до ПЗ.

## Проверка слов

- PyMuPDF `page.get_text("words", sort=False)` и независимый API Poppler
  `pdftotext -bbox-layout` дали по **322** слова на странице 9.
- Существующий строгий `compareCompleteWorkerWordsWithPoppler` вернул
  `WORD_ORDER_TEXT_OR_BOX_MISMATCH`: порядок различен. Только 7 из 322 слов
  совпали по тексту на том же индексе; ни одна рамка не совпала на том же
  индексе. Первое слово PyMuPDF — `Инв.` с рамкой
  `[20715,795017,30759,813780]`, первое слово Poppler — `к)` с рамкой
  `[109140,50332,117517,61514]` (тысячные доли PDF-пункта).
- Полный текст страницы после нормализации пробелов совпал. Новая проверка
  строгого **уникального взаимно-однозначного** соответствия по точному тексту
  и четырём координатам с допуском 100 тысячных пункта сопоставила 322/322
  слов. Дубли, неоднозначные совпадения, пропуски и искажённые рамки приводят
  к отказу. Самостоятельный локальный verifier заново получает Poppler words
  из исходных PDF-байт и затем воспроизводит группировку и все хеши Python
  worker по отдельно переданному полному списку слов в исходном порядке.
- Исходный worker выдал семь **review-only** предложений. Локальный составной
  verifier принял их с `ABSTAIN`, `typedFact: null`, `findingCount: null`,
  `parameterCoverage: null`. Это проверка навигационного пакета, не вывод
  экспертизы.

## Граница доказательства

Poppler подтвердил полный набор текстов и рамок **только на этой странице**.
Порядок `wordIndex` PyMuPDF независимым Poppler не подтверждён: bijection
разрешает разный порядок, а replay проверяет, что результат соответствует
переданному порядку worker. Полный список слов передаётся отдельно от пакета
предложений; одного `wordLayoutSha256` в результате для восстановления порядка
недостаточно. Никакие release/save/seal/GET/UI/Compose маршруты к verifier
не подключены. До применения в них нужны аутентичное происхождение полного
word artifact из конкретного worker run, привязка к immutable original/source
и решение по предметному смыслу PZ-006, утверждённым источникам и паре ПД/РД.

Проверка: `cd apps/api && npx vitest run test/pz006-building-levels-proposals.test.ts`
дала 6/6 PASS при доступном оригинале; `npm run typecheck` PASS. Synthetic
fixture проверяет Python/TypeScript replay, оригинальный тест — только
отдельный локальный review gate. `TEST_HIDDEN` и закрытые ответы не использовались.
