# MATERIAL_CLASS: марки материалов КР для просмотра

28 сентября 2026. Коды `KR-056`, `KR-057`, `KR-066` собраны в отдельный
review-only пакет. [Предметный аудит](NEXT_UNRESOLVED_FAMILY_AUDIT_2_20260928.md)
сверил по SHA разрешённые оригиналы F0106 ПД/КР и F0140 РД/КР и четыре
характерных листа. Совпадение С245 или А500С в двух документах не
устанавливает один физический элемент. Таблица требуемых R/REI не
доказывает фактический состав и толщину огнезащиты.

`material-class-run-review-v1` берёт только committed `document-text-v2`
и immutable решения `CURRENT`/`APPROVED` для однозначной стадии ПД или
РД и секции КР. Все лексические подсказки привязаны к SHA исходного PDF,
странице, блоку и строке. `OCR_REQUIRED` листы остаются отложенными.
Категории отделяют общие требования, табличные заголовки, примечания
листа, требования огнестойкости и упоминания состава. Для каждого
локатора связь с элементом и сопоставление между файлами `UNVERIFIED`;
для `KR-066` фактическая защита `NOT_ESTABLISHED`. Все три кода
`ABSTAIN`, `findingCount` и `parameterCoverage` равны `null`.

Pure worker и opt-in adapter проверены синтетическими тестами.
Независимый API валидатор принимает Python fixture и отклоняет подмену
класса, элемента, фактической защиты и ложный ноль подсказок. Web
показывает только навигацию с SHA-привязанными ссылками. Opt-in
API профиль независимо сверяет immutable источник и committed текст при
save/seal/GET. Полный локальный `npm run check` прошёл: API 291,
web 70, worker 741, сборка. Последовательный PostgreSQL suite:
14 файлов/38 тестов без пропусков. Изолированный homeserver запуск
F0140 `CHK-44D0DC61` прошёл с ZIP/manifest/PDF SHA, 9/9 jobs,
тремя `ABSTAIN`/0 строк, 0 findings и authenticated API/browser smoke.
Положительных решений эксперта не создавали; подробности в
[Compose-отчёте](MATERIAL_CLASS_COMPOSE_20260928.md).
