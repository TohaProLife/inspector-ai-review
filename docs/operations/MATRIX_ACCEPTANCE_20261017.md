# Inspector AI: приёмка общего matrix pipeline, 17.10.2026

## Что работает

Реализован общий путь `PDF bytes → canonical text/OCR → typed observations → scoped atomic rules → independent API verification → immutable execution → frozen JSON`. Используется существующая архитектура Node/Fastify/PostgreSQL/RabbitMQ/Python/React. Новое правило не требует отдельного взаимоисключающего pilot profile.

Реестр содержит 132 параметра: **49 имеют установленную реализацию, 55 атомарных правил; 83 остаются UNSUPPORTED с явной причиной**. При наличии ИД запускаются 84 разрешённые группы стадий; без ИД — 55. Это число установленных правил, не доля полноценно проверенных параметров реального объекта.

Наблюдения и кандидаты штампов доступны при UNKNOWN редакции/согласования. Каждое значение привязано к SHA оригинала, странице, исходному блоку/строке и видимой рамке. Неизвестные согласование, сущность, полнота и применимость нормы не назначаются автоматически. Отдельная единица из заголовка таблицы остаётся неподтверждённой.

Python считает точными Decimal; API независимо проверяет исходный текст, рамку, нормализацию, контексты, атомарные результаты и покрытие. Пропуск результата, подмена чужого источника/элемента, единицы или статуса отвергаются. Release закрепляет реестр и SHA исходника engine.

Машинная уверенность отделена от OCR score и человеческого решения. Порог предупреждения — **неокруглённое p ≥ 0.80**, только при достаточных доказательствах и действующей версии калибровки. `0.7996`, null, OOD и технический сбой проверены отдельно. **Текущий профиль не имеет измеренной калибровки; вероятность null, машинные выводы остаются кандидатами.**

Локальная привязка двух листов сохраняет точные SHA/страницы, этаж/фазу, соответствия, преобразование, область опор, остатки и погрешность. Минимум 3 неколлинеарные FIT + 1 независимая HOLDOUT. Свободная подгонка по проверяемому контуру и экстраполяция запрещены; affine требует основания искажения скана. Без метрического масштаба нет вывода в метрах. `absoluteGeoreference=false`: локальная регистрация не доказывает положение объекта на местности.

Машинный JSON сохраняется отдельно от review в append-only snapshot. API возвращает канонические сохранённые байты; SHA ответа совпадает с БД и `X-Content-SHA256`. Человеческая привязка и перезапуск сервисов не меняют прежнюю выгрузку. Публичные object/file ID подставляются только по точному SHA и стадии из versioned public manifest; иначе явно остаются ID приложения.

Новая волна T07: насосный расход/напор, секции/теплоотдача радиатора, расход/давление дымового вентилятора, толщина асфальта/щебня. Проверяются отдельные совпадающие позиция, зона, режим и база измерения; разные режимы дают отказ. У этих четырёх составных параметров сохраняется catalog gap: числовые части работают, автоматический инвентарь и отсутствие слоя не объявляются готовыми. [Контракт T07](MATRIX_T07_BOUNDED_SUBRULES_20261017.md), [карта 132 параметров](PARAMETER_IMPLEMENTATION_20261017.csv).
