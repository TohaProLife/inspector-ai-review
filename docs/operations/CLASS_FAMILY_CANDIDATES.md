# Классовые кандидаты из публичного индекса

`class_family_candidates.py` адресует одну страницу разрешённого публичного PDF
и извлекает буквальные классы для **ровно восьми** правил семейства
`CLASS_DECREASE`: `PZ-015`, `PZ-021`, `PZ-022`, `PZ-023`, `AR-050`,
`PPM-103`, `PPM-107`, `ZU-124`. `KR-055` относится к пилотному правилу и не
входит в этот пакет 47 кандидатов.

Подписи строк равны точным названиям параметров в
`parameter_catalog_132.jsonl`; допустимые значения перечислены в
`class-family-labels-v1.json`. Пакет сверяет SHA каталога и 47 правил, список
кодов, атрибутов, подписей и значений. Для категорий надёжности приняты
буквальные `1`–`3` и `I`–`III`; для энергоэффективности — одиночные буквы;
для степени огнестойкости — `I`–`V`; для конструктивной опасности — `С0`–`С3`;
для отделки — `КМ0`–`КМ5`; для дверей — записи `EI`, `E`, `I` с одним
явным числом минут из закрытого словаря. Это **словарь кандидатов**, а не
нормативная шкала или подтверждение правильности обозначения на объекте.
Его надо расширять только после проверки конкретных строк публичных PDF.

Строка должна состоять из одной точной подписи, разделителя и одного
допустимого значения. Дополнительное значение, отрицание, альтернативы,
другая подпись или две подходящие строки на выбранной странице дают пустой
результат. Извлекатель не выбирает один из нескольких классов и не переносит
значение из соседней строки таблицы. Так мы сохраняем точный текст строки и
координаты, не приписывая класс другому зданию или помещению.

Вход `extract_indexed_class_family_candidates(...)` проходит
`load_indexed_page_evidence`: публичный манифест, `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`,
SHA источника и артефакта страницы, полноту исходного PDF, качество текста и
исходные индексы блоков. `OCR_REQUIRED` требует отдельного адресного OCR.
Стадия обязана быть `PD` либо `RD` согласно правилу. Если категория раздела
манифеста не устанавливает нужный раздел ПД (`PZ`, `PPM`, `ZU`), вызывающий
передаёт подтверждение раздела со стадией, SHA источника/манифеста и ссылкой
на проверку. Иная марка внутри категории требует отдельное подтверждение
марки. Входное `OTHER` само по себе не считается подтверждением.

Выход содержит исходную строку и `rawValue`, bbox и адрес строки, SHA
источника/страницы/выбранного доказательства, SHA правил и словаря. Статус
всегда `CANDIDATE`, политика `NON_EXECUTING_ABSTAIN`. Ни ранг класса, ни
снижение, ни связь ПД/РД, ни редакция, ни finding или coverage не выводятся.
После пакетной проверки реальных PDF нужны проверка области действия класса,
сопоставление того же элемента/места, утверждённая шкала и review источников.

Проверка:

```bash
PYTHONPATH=services/worker uv run --no-project \
  --with 'pdfminer.six==20260107' --with 'PyMuPDF==1.27.2.2' \
  python -m unittest services.worker.tests.test_class_family_candidates -q
```

Тесты проверяют все восемь кодов, ложные совпадения по области/домену,
многозначность, отрицание, стадию и раздел, привязку подтверждения к SHA,
повреждённое доказательство и артефакт страницы. Один тест строит и читает
реальный локальный PDF через индекс; при отсутствии шрифта с кириллицей он
пропускается. Пакетная точность на конкурсных PDF пока не установлена.

## Полный просмотр корпуса

`class_label_probe.py` и `scripts/probe-public-class-labels.py` выполняют
один последовательный read-only проход по всем **202 PDF / 10 142 страницам**.
Запуск требует отчёт `audit-public-document-index.py` со статусом `PASS`,
совпадающими SHA манифеста и версией индекса, 203 источниками, 10 142
сверенными артефактами и полным FTS. F0194 остаётся строкой инвентаря:
его тело не открывается. Каждый PDF и каждая страница сверяются с
манифестом; gzip-артефакт страницы повторно проверяется по SHA и FTS.

```bash
python3 scripts/probe-public-class-labels.py \
  --manifest datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --index /path/to/public-index \
  --audit /path/to/index-audit.json \
  --max-examples-per-code 20 \
  --max-ocr-queue 2000 > /path/to/class-label-probe.json
```

Отчёт считает точные строки, страницы с несколькими значениями и строки,
где та же подпись соседствует с похожим, но не принятым значением
(`nearMissLines`). Это лексический обзор всех разделов, ещё не проверка
допустимой пары ПД/РД. Отдельные списки точных и близких примеров ограничены
20 на код и вид, усечения указаны явно. `ocrQueue` содержит адреса страниц
`OCR_REQUIRED` с SHA источника и страницы; такие страницы требуют выбора для
адресного OCR, а не массовой автоматической обработки. Если очередь превышает
лимит, `ocrQueueTruncated` это показывает. Очередь не означает, что на странице
есть нужный класс.

```bash
PYTHONPATH=services/worker uv run --no-project \
  --with 'pdfminer.six==20260107' --with 'PyMuPDF==1.27.2.2' \
  python -m unittest services.worker.tests.test_class_label_probe -q
```

### Фактический полный проход, 27 сентября 2026

На homeserver проверены все 203 записи манифеста: 202 PDF, 10 142 страницы.
Из них 8 668 имеют `TEXT_LAYER_CANDIDATE`, 1 474 требуют адресного OCR.
Очередь OCR содержит все 1 474 адреса без усечения. Отчёт:
`/mnt/edberries-backup-disk/inspector-ai-dataset-20260924/family-batches/class-label-probe-20260927.json`,
SHA-256 `e8dacf8573f07474e01089405afc459e8d9f88184a6cf8008c68c1c8aa6cf98c`.
SHA публичного манифеста `853225daec1888fbed19bbeb45e958154135f069799cea883dcd3c754c6c4ee7`
совпал с отчётом аудита `PASS`; SHA самого отчёта аудита в результате также
совпал. Код и словарь в изолированном checkout имеют те же SHA, что локальные.

По восьми кодам найдена **одна точная строка**: `PZ-022`, F0193, страница 18,
«степень огнестойкости здания – I;». Две близкие строки: `PZ-015`, F0118,
страница 12 («Категория надежности электроснабжения насосных станций принята II.»),
и `PZ-023`, F0193, страница 18 («класс конструктивной пожарной опасности здания – С0;»).
Остальные коды дали ноль точных и близких строк. Это измеряет лишь совпадение
строгой подписи с доступным текстовым слоем. Нули не означают отсутствие
классов в документах: запись может быть сокращена, находиться в таблице,
на скане или использовать другую формулировку. Сопоставление ПД/РД и
предметная точность не проверены. После адресного разбора и прохода v2
локально и в контейнере homeserver прошли 18/18 тестов; на homeserver один
тест с реальным PDF пропущен из-за отсутствия кириллического шрифта.

Все три строки остаются **лексическими совпадениями**, допустимых кандидатов
ПЗ из них сейчас **0**. Строки p.18 не объявлены целиком нормативной цитатой:
пункт 6.1 формулирует проектные характеристики, но источник и идентичность
объекта для этих правил не подтверждены. Новые алиасы для трёх строк не
добавлены: они расширили бы совпадения на неподходящие разделы. Следующий
проход должен проверять альтернативные подписи только на документах с
доказанным разделом и областью объекта.

Версия `class-label-probe-v2` отдельно записывает `sourceEligibility` для
каждого примера и счётчик таких статусов по коду. Для этих трёх адресов по
метаданным статус `DRAWING_SECTION_RESOLUTION_REQUIRED`; проверка титульных
страниц выше даёт ручное решение не принимать их как источник ПЗ.

Полный проход v2 на том же индексе завершён:
`/mnt/edberries-backup-disk/inspector-ai-dataset-20260924/family-batches/class-label-probe-20260927-v2.json`,
SHA-256 `6b5e86f002fd23cf7dabf8117ce841b54e73d7672465b81ce4597b26df327ab5`.
Отчёт повторно проверил все 203 источника и 10 142 страницы: для каждого PDF
`verifiedPages == expectedPages`. По сравнению с v1 совпали инвентарь,
итоговые счётчики, записи источников и все 1 474 адреса очереди OCR.
Лексические результаты также неизменны: одна точная строка `PZ-022`, две
близкие `PZ-015` и `PZ-023`, ноль неоднозначных страниц. В v2 у каждого
примера добавлены стадия, раздел и SHA источника, объект и статус допустимости
источника. Для каждого из трёх совпадений он равен
`DRAWING_SECTION_RESOLUTION_REQUIRED`. Его нельзя считать положительной
проверкой раздела; после проверки титулов допустимых кандидатов ПЗ из этих
строк нет. Отчёт имеет `REVIEW_ONLY`, `findingCount=null` и
`parameterCoverage=null`. Полный проход не доказывает отсутствие классов на
1 474 страницах без подходящего текстового слоя.
