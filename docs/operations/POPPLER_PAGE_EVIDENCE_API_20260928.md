# Независимая API-проверка Poppler page evidence v1

`apps/api/src/poppler-page-evidence.ts` повторно читает оригинальные байты PDF
и проверяет весь пакет `poppler-page-evidence-v1`. Вызывающий код обязан
передать доверенные SHA-256, размер, число страниц и выбранные страницы из
immutable run/source snapshot. Доступ к разрешённому документу и решение
`CURRENT/APPROVED` проверяются отдельно; этот модуль их не утверждает.

До чтения PDF через Poppler API проверяет байты и SHA, пределы 64 MiB,
10 000 страниц и четыре строго возрастающие выбранные страницы. Оба
бинарника `pdftotext` и `pdfinfo` обязаны иметь версию ровно `25.12.0`.
API независимо выполняет `pdfinfo`, `pdftotext -bbox-layout` и `-raw` из
приватной копии оригинала. Для каждой страницы сверяются полный порядок
и координаты не более 5000 слов, текст, геометрия, SHA сырых потоков,
хеш списка слов, хеш страницы и общий canonical contentHash. Лишнее
поле либо сокращённый список отклоняется.

Положительная проверка означает только точную воспроизводимость извлечения
для выбранных страниц. `absenceConclusion=NOT_AVAILABLE`, facts/findings/
coverage остаются null. Сканирование всех страниц документа, смысловая
применимость, авторитетность источника, пара ПД/РД и отсутствие объекта
не подтверждаются. Durable save/seal/GET и release profile пока не подключены.

Локальные synthetic тесты: `npm --workspace apps/api exec vitest run
test/poppler-page-evidence.test.ts` (5/5), API typecheck прошёл.
Независимый replay по исходному разрешённому F0152 (`SHA-256
99ec972d7dfe5039fca922e3120bd5e486f2a26518f78044d0850992c028e7af`)
проверен в отдельном API-образе
`sha256:8ce2e25818ffbdb3eb6ced875fa977e6f26b764da0c084e78879117c69dece6b`
с Poppler `25.12.0`, без сети и с read-only filesystem. Worker JSON
сформирован отдельно в pinned worker-образе из тех же оригинальных байтов.
Проверка API вернула 135/173 слов на с.49/51 и тот же
`contentHash=074041a83a3a52c724cd8c4bf47f65cdf1ae3f0e6b66988d615496bc0a83eb26`.
Удаление одного слова из рабочего пакета в том же контейнере отклонено.
Обычный API-контейнер не заменялся; это отдельная проверка, без durable
save/seal/GET и без положительного решения эксперта.
