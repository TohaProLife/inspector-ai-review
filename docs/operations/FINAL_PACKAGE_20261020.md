## H100

Следовать [H100_READINESS_20261020.md](H100_READINESS_20261020.md). Все команды выполнять из корня source рядом с `package.json`; файлы V9 уже включены. API overlays, source-map и `output/` старого checkout для сборки не требуются.


Ожидаются пять исходов конфигурации и три resource merge. Этот скрипт не запускает GPU. H100 hardware/CUDA/inference здесь не проверены. На целевом стенде обязательны назначенные hostname/GPU UUID, доступный закреплённый model cache и runtime/inference preflight. Модельные веса в этих ZIP отсутствуют. Offline Compose PASS не заменяет аппаратный запуск.

## Что показать в интерфейсе

1. Создать объект, загрузить PDF, дождаться ClamAV и завершения NORMAL. Полный V4 audit запускается отдельным действием и сохраняет собственный release; он не расширяет инженерный V13 молча.
2. Открыть исходную страницу и парный viewer: ПД слева, РД справа; независимые страницы/масштаб, переход к цитатам, подсветка native областей, поиск, fullscreen и связь прокрутки. [Приёмка viewer](PAIR_VIEWER_ACCEPTANCE_20261020.md).
3. В завершённом полном V4 сохранить выбранную сверку вместимости или вентиляции. Доступны история и JSON; реальные примеры: 600=600 мест и П17 9060=3340+5720 м³/ч. Состав группы выбирает пользователь; давления 350/540 Па показаны отдельно. [Вместимость](NATIVE_CAPACITY_ACCEPTANCE_20261020.md), [вентиляция](NATIVE_AIRFLOW_ACCEPTANCE_20261020.md).
4. В источнике полного V4 открыть отдельный OCR workspace. Сохранённый bundle companion: `audits/native-ocr-import-engine-v1/F0201-source-ocr-import-bundle-v1.json`; он подходит только к точному F0201 и его полному V4 с совпадающими SHA/gap pages. Импорт не запускает OCR. Поиск, страницы, ручная сверка строк с основанием и история сохраняются; JSON читается после перезагрузки. [Приёмка OCR](SOURCE_OCR_IMPORT_ACCEPTANCE_20261020.md).
5. В OCR workspace открыть «Кандидаты для сверки единиц». На F0201стр.8 один кандидат:107,687кВт(0,926Гкал/час). Кнопка открывает нужную строку и PDF; подсказка остаётся после ручного подтверждения текста. Исходные числа не исправляются. [Приёмка](SOURCE_OCR_UNIT_QUALITY_20261020.md).
6. Открыть сохранённую версию протокола, скачать PDF/DOCX/XML/JSON. Кириллица и семь разделов приложения 2 берутся из immutable canonical snapshot. [Приёмка экспорта](PROTOCOL_EXPORT_ACCEPTANCE_20261020.md). Authenticated ИАИС pull facade доступен для действующего NORMAL FINAL; это хакатонный контракт, без внешней доставки и электронной подписи.

Права зависят от роли: импорт OCR требует RUN_START, сверка строки — SOURCE_REVIEW/REVIEW_DECIDE; чтение остаётся ограничено организацией и объектом. Ручная сверка OCR подтверждает только буквальный текст, не инженерное нарушение. Координаты внешнего растра не рисуются как достоверные PDF bbox.
