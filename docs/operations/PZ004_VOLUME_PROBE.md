# PZ-004: ограниченное наблюдение строительного объёма

27 сентября 2026. Автономный зонд читает только два исходных PDF из
`TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`: `F0150` (ПД, PDF с. 26) и `F0201`
(смешанный РД/ИД, ОВ, PDF с. 14). Перед чтением листов проверяет SHA-256
публичного `document_manifest.jsonl`, размер, SHA-256 и число страниц каждого
PDF. Ответы и `TEST_HIDDEN` не используются. Страницы заданы явно как
исследовательский срез; автоматический поиск по комплекту здесь не проверен.

Каталог определяет `PZ-004` как общий строительный объём в м³. Для ПД ожидает
таблицу ТЭП раздела ПЗ, для РД — «Общие данные» раздела АР/КР; trigger
относится к изменению внешних габаритов без корректировки ПД. Это требует
связи комплектов, актуальных редакций, согласования, геометрии и применимой
корректировки. `F0201` относится к разделу **ОВ**, хотя на листе напечатан
объём здания. Этот файл не заменяет требуемый РД АР/КР. `RD_ID_MIXED` в
манифесте сам по себе не удостоверяет стадию страницы.

## Реальный запуск на homeserver

На исходных `F0150_raw.pdf` и `F0201_raw.pdf` локальный контейнер worker
работал без сети, с пределами 2 CPU / 3 ГБ RAM. Текст прочитан напрямую из PDF
через PyMuPDF. Проверенный манифест имеет SHA-256
`853225daec1888fbed19bbeb45e958154135f069799cea883dcd3c754c6c4ee7`.
Результат сохранён на homeserver в
`/tmp/inspector-pz004-volume-20260927/output/report.json` и скопирован в

корректировки. Нулевая числовая разница также не доказывает отсутствие
нарушения по внешним габаритам.

## Повторение

[`probe-pz004-volume-public.py`](../../scripts/probe-pz004-volume-public.py)
принимает только локальные пути. Значение `--expected-manifest-sha256`
по умолчанию закреплено за открытым пакетом участника; для синтетических
fixtures можно передать свой ожидаемый SHA-256.

```bash
python scripts/probe-pz004-volume-public.py \
  --manifest /path/to/document_manifest.jsonl \
  --pd-source /path/to/F0150_raw.pdf \
  --mixed-source /path/to/F0201_raw.pdf \
  --output /path/to/pz004-observations.json
```

Worker-only модуль
[`pz004_volume_observations.py`](../../services/worker/inspector_worker/pz004_volume_observations.py)
не подключён к durable rule, API coverage или выпуску finding. Восемь адресных
тестов проверяют две исходные строки, разные значения без finding, отсутствие
значения, повтор строки, чужой scope/единицу, неверный manifest/PDF, раздел/стадию/split,
объект и число страниц:

```bash
PYTHONPATH=services/worker python -m unittest \
  services/worker/tests/test_pz004_volume_observations.py -v
```

Для реализации правила нужны проверенный источник РД АР/КР, source review,
геометрия внешних габаритов и применимость корректировки ПД. До этого
`PZ-004` остаётся неподдержанным в общем coverage.
