# Геометрическая рамка v2: навигация без предметного вывода

`geometry-page-frame-v2` — отдельный чистый пакет для ручного просмотра страницы. Worker берёт raw `MediaBox`, `CropBox`, `Rotate` из исходного PDF через PyMuPDF, рендерит одну страницу фиксированным профилем `pdftoppm` 72 DPI и сохраняет SHA исходника и PNG. Статус всегда `ABSTAIN`, `candidates=[]`; пакет не содержит контуров, CRS, масштаба, реперов, пары ПД/РД, findings или coverage.

Независимый API verifier повторно рендерит тот же оригинальный PDF установленным `pdftoppm` с закреплённой версией и требует побайтового совпадения PNG. `pdfinfo -box` сообщает координаты с двумя знаками; verifier допускает raw worker-координату только строго внутри интервала ±0,005 пункта вокруг печатного значения. Это явно названная точность **для ABSTAIN-навигации**. Неопределённость не используется для положительного пространственного предиката или автоматического назначения типа контура. Подмена SHA, страницы, PNG, профиля, шага точности, поворота, статуса и непустые кандидаты отклоняются.

На исходном разрешённом F0126 с.17 (PDF SHA `b4846376535dd97aa24a8e384e0cb71f40792084fc61981dad587b15bbf63088`) worker packet и PNG проверены независимым API: 3/3 TS теста, включая публичный Python→TS parity, прошли. PNG SHA `a1aca1ee57070b4bec5182741bfba296621875eec802c31bd09280c10b61f24a`; SHA по канонизации API `f14cc7b1b95e29a33dc2425ffa9da10454a72fdfb7d6d7d1125ed4996c2111f5`. Python `json.dumps(sort_keys=True)` даёт другой SHA из-за отличного порядка ключей; при сохранении нужно использовать именно серверный canonical JSON. Worker профильные тесты прошли 5/5. Файлы исходника и PNG для parity лежат временно в `/tmp`, не являются частью репозитория.

Дополнительный strict verifier использует [независимый raw page-tree parser](GEOMETRY_RAW_PAGE_TREE_READER_20260928.md) и требует точного равенства каждого worker float с явным `Math.fround` исходного числового операнда PDF. На публичном F0126 с.17 strict Python→TS путь также прошёл; неподдержанные PDF отвергаются. Даже эта проверка подтверждает рамку листа, а не сами контуры. Текущий v1 контракт с точным равенством box остаётся неизменным. V2 пока не подключён к release/save/seal/GET или UI. Для положительного геометрического сравнения требуются регистрация контуров/точек, шкалы, CRS и исходных решений по источникам. Подробнее: [аудит точности](GEOMETRY_POPPLER_PRECISION_AUDIT_20260928.md) и [план геометрии](GEOMETRY_EVIDENCE_PIPELINE_PLAN_20260928.md).
