# DOCUMENT_APPROVAL и SAFETY_COVERAGE: второй пакет подсказок

28 сентября 2026. Отдельная конфигурация `unresolved-review-config-v2`
закреплена каноническим SHA-256
`1c31aad1761af86273f421daef5fc04bfe7724c9bf07750a1f1b8b37be30a0e8`.
Она задаёт пять кодов `DOCUMENT_APPROVAL` и пять `SAFETY_COVERAGE`.
Шестнадцать буквальных поисковых якорей проверены на разрешённых
оригинальных PDF с SHA файла, физической страницы и рендера в
[предметном аудите](NEXT_APPROVAL_SAFETY_AUDIT_20260928.md).

Пакет возвращает только адреса строк из подтверждённых текстовых слоёв
конкретного запуска. Локаторы привязаны к SHA исходного PDF, текстового
артефакта, блока и строки; bbox относится к **блоку**. Страницы
`OCR_REQUIRED`, неподтверждённые стадии и длинные строки явно
откладываются. Строка о материале, двери, приборе или согласовании не
доказывает идентичность элемента, применимость нормы, факт замены или
наличие подписанного решения.

Все десять кодов имеют `ABSTAIN`; `findingCount` и
`parameterCoverage` равны `null`, вывод об отсутствии недоступен.
Конфигурация v1 для 19 других кодов и её SHA не изменены. Pure worker
v2 прошёл 12/12 профильных и 755/755 общих тестов; синтетический v1
вывод побайтно совпал с прежним fixture. Независимый API verifier и
отдельный API-owned pinned config приняли обе Python fixture с десятью
строками и смешанной постраничной стадией, отвергли подмены: 6/6
тестов, typecheck PASS. API не воспроизводит физический PDF render;
его SHA закреплён в проверенной публичной конфигурации.
Отдельный opt-in worker adapter использует профиль
`typed-pz002-pz017-unresolved-config-review-v2` и возвращает три output
записи, включая `unresolvedConfigReviewV2`; старый v1 не меняется.
Профиль выбирается `INSPECTOR_UNRESOLVED_CONFIG_REVIEW_PROFILE=v2`.
API хранит pinned v2 config в immutable release и пересчитывает источник,
текст и результат при save/seal/authenticated GET. Синтетический
PostgreSQL тест проверил одну строку для `SPZU-026`, отсутствие результата,
подмены sidecar/config/text и смешение v1/v2; последовательный suite
16 файлов/40 тестов прошёл. Web панель показывает только ABSTAIN и
SHA-связанные страницы; web 75/75 PASS. Полный локальный
`npm run check` после исправления OpenAPI имени схемы и абсолютного
пути интерпретатора в installed-layout тестах прошёл: API 302,
web 75, worker 760 и сборка. Изолированный Compose на разрешённом F0156
`CHK-3F610706` завершён: оригинальные ZIP/manifest/PDF SHA сверены,
10/10 jobs успешны, sealed `PARTIAL`, 0 findings, десять `ABSTAIN`/0
подсказок без подтверждённого источника. Авторизованный API, отказ
анонимному запросу, браузерный просмотр и неизменность v1 stage прошли.
