# Сверка разметки с первоисточниками — 26 сентября 2026

## Решение

Самостоятельно проверены 16 предложений по исходным PDF `TRAIN_PUBLIC`, подписанным узлам на листах и документации производителей. Итоговый снимок: [16 строк `AI_CROSSCHECKED`](../../datasets/annotations/train_public_symbols_v0/source_crosschecked_labels.jsonl), из них **2 петли тёплого пола, 9 радиаторов и 5 локальных отрицательных областей**. Исходные [предложения](DRAWING_LABEL_REVIEW_QUEUE_20260925.md) сохранены без изменения. `HUMAN_APPROVED` не присваивался; человек эти 16 решений не утверждал.

Три области `HEATING-AI-0003`–`0005` переклассифицированы из отрицательных для `HEATING_LOOP` в положительные `RADIATOR`. Их [старые PNG с рамкой](../../datasets/annotations/train_public_symbols_v0/review/) всё ещё показывают заголовок исходного предложения; текущий класс задаёт только новый JSONL. Геометрия рамок не менялась. Помещения двух приборов под петлями оставлены неопределёнными; у прибора в помещении 277 связь однозначна.

## Почему изменён класс трёх приборов

- На F0171, странице PDF 99, под двумя спиралями и в помещении 277 стоят прямоугольные приборы с нижним подключением к `Т11/Т21`: [фрагмент плана](../../datasets/annotations/train_public_symbols_v0/review/F0171-p99-source-plan.png).
- **Тот же лист** содержит подписанные типовые узлы [радиатора](../../datasets/annotations/train_public_symbols_v0/review/F0171-p99-source-radiator-nodes.png) и [регистра из труб](../../datasets/annotations/train_public_symbols_v0/review/F0171-p99-source-register-nodes.png). Области `0003`–`0005` соответствуют прямоугольному радиатору; регистр изображён иной, трубчатой формой. Это вывод из самого проекта, а не из одного лишь сходства прямоугольников.
- Текстовая часть F0171 прямо перечисляет панельные радиаторы PRADO, трубчатые регистры и отдельный электроконвектор. Для помещений 267, 270, 271, 272 указаны одновременно тёплый пол и радиаторное отопление. Поэтому приборы под петлями не являются «пустым фоном» многоклассового детектора.
- [ГОСТ 21.205-2016 на портале Росстандарта](https://protect.gost.ru/gost/details/145b9995-43b6-481c-b293-2f6d194a2806) распространяется на обозначения отопления и вентиляции. В его таблице 9 радиатор, регистр/конвектор и электрический нагревательный прибор перечислены отдельно. Стандарт использован для границы таксономии; точный класс на этом проекте устанавливается по подписанным узлам самого F0171.

Источник F0171 сверен с `document_manifest.jsonl`: SHA-256 `a9070055b75adeea0d47651cf9dca3ca818ca5f54ac7ce9ddcd86efc817db7dc`, `TRAIN_PUBLIC/INCLUDE`. Фрагменты выше отрисованы из этого PDF при 200 dpi. Их SHA-256: план `3f06eebb631a1287f3d74eb4aba60282c7da35b397e543add6a851889957c365`, узлы радиатора `12659c174ea7aafb0c35157f45e61cd36d05728d05687d1fb2db24bbc30e3371`, узлы регистра `1f099e657ba8ad0cad496c101f736df273378067bee2790bcdff8e4d3016e0d5`.

Не присваивалась модель PRADO каждому из трёх приборов F0171: их класс радиатора подтверждён, марка конкретного экземпляра не доказана.
