## Реализованная грамматика РД

Только `stage=RD`, `attribute=CONCRETE_CLASS`, `valueKind=CONCRETE_CLASS`.
`fullmatch` выполняется над строкой после свёртки пробелов:

```regex
(?i:Класс бетона по прочности на сжатие)\s+(?P<value>[BВ]NUMBER)(?:,\s*(?i:марка по морозостойкости)\s+F[0-9]+)?(?:,\s*(?i:марка по водонепроницаемости)\s+W[0-9]+)?\.?
```

`NUMBER` — существующий беззнаковый десятичный шаблон engine, включая точку или
запятую. Каждая именованная марка допускается не более одного раза, F перед W.
Неизвестные хвосты, повторные значения, диапазоны и альтернативы не совпадают.
«Класс бетонных поверхностей ... А6» не является классом прочности бетона.
Новая форма не применяется к ПД, ИД и неразрешённой смешанной стадии. Старые
литеральные подписи продолжают работать по прежним правилам.

Реестр не изменён: canonical SHA-256
`c74a27dc212fa327253537679e82faa428328edfbda1161e7cc66aa25a104b04`.
Исполняемые байты engine проверяются отдельным SHA pin в durable job.
