## Реальный путь исполнения

Публичный source-audit-v3 запускает обычный durable DAG. Review хранит exact native source selection, server-reconstructed declaration, original SHA и явное соответствие позиции светильника. Полный v3 origin берётся из сохранённого аудита; worker не может прислать готовое утверждение вместо него. Внутренний v5 loader защищён token/attempt/fence; API сверяет текущие review и исходные PDF до и после скачивания. При complete/seal/read API независимо пересобирает все пять typed сравнений и coverage.

Web показывает аудит отдельно от обычной проверки; позволяет выбрать точные исходные строки, проверить preview, записать или отозвать привязку с CAS. Lighting evidence открывает точные первичные фрагменты оригинала. v9 использует confidence-v2: предупреждение только при квалифицированной калиброванной уверенности **строго больше 80%**; ровно 80% и неизвестная вероятность остаются кандидатами. Старые запуски сохраняют v1 и прежние байты. Human confirmation не создаётся автоматически.
