# ZU-127 generic v3: граница durable-интеграции, 28.09.2026

Подготовлен отдельный review-only профиль `zu127-generic-poppler-page-review-v3`. Его release descriptor закрепляет SHA конфигурации `e593f2298e672177bbeac05cd9b6cda6f4926a3a9260ea3b3c35dbf63010264c`, не разрешает внешний интернет и не меняет старые release. Выбор профиля через переменную окружения пока закрыт: нельзя отправить работу в специализированную очередь до готовности потребителя и независимой проверки сохранённого результата.

Имя очереди `rules.evaluate.zu127.poppler-v3` выводится из сохранённого release, а claim для неё требует явного совпадения имени очереди. Outbox объявляет отдельную очередь и DLQ. Эти изменения не означают, что профиль запущен в обычном Compose.

API получил приватную загрузку входа из immutable run: manifest, original blob SHA/размер, snapshot решения об источнике и `document-text-v2` успешной text-стадии проверяются повторно. Отдельный reader считывает оригинальные PDF-байты из API-owned object storage в пределах 64 МиБ на файл и проверяет размер, SHA и сигнатуру. Worker не может передать API произвольный путь к файлу. Синтетический PostgreSQL тест загрузчика проверил положительный путь и подмену review, text, job, manifest и blob SHA. В рамках реального публичного корпуса положительных решений `CURRENT/APPROVED` не создавали.

На этом этапе загрузчик и reader сами по себе не дают durable результат. До активации профиля необходимы полноценный consumer, независимая повторная проверка v3 при save/seal/GET, PostgreSQL tamper-тесты всего пути и изолированный Compose на оригинальном разрешённом PDF. Результаты ZU-127 остаются `ABSTAIN` без findings и coverage.
