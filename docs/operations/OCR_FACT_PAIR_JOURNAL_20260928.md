# Отдельное решение о паре фактов OCR_ROW

Миграция 026 добавляет append-only журнал решений о конкретной паре
`typed-fact-v2` из разных исходников ПД и РД. Запрос содержит только ID
фактов, SHA локаторов, общий контекст и явное решение эксперта с основанием.
При записи и чтении API повторно проверяет неизменяемый OCR_ROW артефакт,
снимки решений по источникам, PDF SHA, стадию, раздел, группу источников,
код, атрибут и идентичность элемента. Подмена сохранённой записи отвергается.
`PAIR_REJECTED` и `UNSURE` остаются отрицательными; `PAIR_CONFIRMED`
лишь разрешает дальнейший предметный разбор. Журнал не создаёт сравнение,
finding или coverage и не использует старый компаратор `TEXT_BLOCK`.

Web показывает происхождение обоих фактов, исходные страницы, хеши и
историю решений. Для сохранения нужны явный выбор решения, основание и
открытие обеих исходных страниц. Поля пусты по умолчанию.

  Это не реальное экспертное решение.
