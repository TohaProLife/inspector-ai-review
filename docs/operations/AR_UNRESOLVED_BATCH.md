# Пакетная проверка неразрешённых параметров АР

Пакет: `AR-042`, `AR-043`, `AR-044`, `AR-045`, `AR-046`, `AR-047`, `AR-048`, `AR-051`, `AR-052`. Источник определений — неизменённый `parameter_catalog_132.jsonl`; стратегия семейств — `unresolved-parameter-strategy-v1.json` со статусом `DESIGN_ONLY`.

## Граница доказательства

Скрипт [batch-ar-unresolved-public.py](../../scripts/batch-ar-unresolved-public.py) один раз просматривает уже построенный индекс v3: 203 разрешённых источника `TRAIN_PUBLIC/INCLUDE/PUBLIC_TRAIN`, 10 142 страницы PDF. Индекс, манифест, аудит, каталог и реестр проверяются по SHA. ZIP/PDF заново не извлекаются. На страницах с текстовым слоем проверяются узкие выражения из девяти групп, адрес каждой строки и геометрия строк-кандидатов таблиц. Страницы `OCR_REQUIRED` получают только план адресного OCR; OCR здесь не запускается.

Найденная строка — повод для ручного просмотра, **не значение параметра**. Поля `findingCount` и `parameterCoverage` равны `null`, итог каждого кода — `ABSTAIN`. Отчёт не утверждает отсутствие параметра на страницах без читаемого текста и не сравнивает разные редакции, элементы или определения величин.

Источник с `section=OTHER` не становится АР только по наличию похожих слов. Для девяти кодов нужны подтверждённые ПД/АР и РД/АР одного объекта. В публичном манифесте есть 3 источника ПД/АР (125 страниц) и **нет РД/АР**. Поэтому даже хорошая строка в PDF не даёт пары документов для исполнения правил. Возможные РД со значением `OTHER` остаются на проверку титула и раздела; `RD_ID_MIXED` также требует подтверждения стадии.

Каждая запись отчёта содержит исходные `sourceFileId`, относительный путь, SHA PDF, объект, стадию и раздел из манифеста, страницу, SHA индексного артефакта, адрес строки и координаты PDF. `GEOMETRIC_TABLE_ROW` присваивается только строке, чьи текст, адрес и прямоугольник в пределах страницы совпали с кандидатом таблицы. Не прошедшая геометрию строка не используется как доказательная таблица. Узкие выражения не заменяют проверку чертежа: направление двери, уклон, слой кровли, положение окна или лестницы требуют визуальной и объектной привязки.

## Запуск на homeserver

Запуск выполняется в отдельном временном каталоге, с передачей локального модуля и pinned audit/strategy. Каталог и реестр читаются из изолированного checkout `inspector-ai-homeserver-smoke`; пути можно передать через аргументы CLI. Пример после передачи файлов:

```bash
python3 /tmp/ar-unresolved-20260927-run/scripts/batch-ar-unresolved-public.py \
  --manifest /home/freetok/Projects/inspector-ai-homeserver-smoke/datasets/reference_methodology/hackathon_gold_20260811/УЧАСТНИКАМ_БЕЗ_ОТВЕТОВ/data/document_manifest.jsonl \
  --index-root /mnt/edberries-backup-disk/inspector-ai-public-document-index-v3-20260927 \
  --audit /tmp/ar-unresolved-20260927-run/index-audit.json \
  --strategy /tmp/ar-unresolved-20260927-run/unresolved-parameter-strategy-v1.json \
  --catalog /home/freetok/Projects/inspector-ai-homeserver-smoke/services/worker/rules/parameter_catalog_132.jsonl \
  --registry /home/freetok/Projects/inspector-ai-homeserver-smoke/services/worker/rules/parameter-family-registry-v1.json \
  --output /tmp/ar-unresolved-20260927-run/report.json
```

Публичный отчёт копируется в `output/ar-unresolved-20260927/report.json`. Повторный запуск даёт тот же JSON/SHA при неизменных индексных файлах. Поля `leadsTruncated` и `queueTruncated` явно показывают лимиты вывода; счётчики при этом считают все проверенные строки.

## Результат реального прохода

Отчёт: [report.json](../../output/ar-unresolved-20260927/report.json), SHA-256 `d2d97651431f4e3fc2fe73c73d4c83306be2081848431ee1140820096914e3e0`. Все 371 строки включены; ограничение вывода не сработало.

Проверены 8 668 страниц `TEXT_LAYER_CANDIDATE`; 1 474 страницы `OCR_REQUIRED` оставлены неизвестными. Отброшены 825 строк с вырожденной или выходящей за страницу геометрией; строк-кандидатов таблиц с недопустимой геометрией не найдено. В девяти группах получено 371 текстовое совпадение, среди них 16 строк таблиц с проверенной геометрией. Совпадения распределены так: 36 в ПД/АР, 215 в ПД с неразрешённым разделом, 120 в источниках с неподходящей ролью. В РД/OTHER и `RD_ID_MIXED/OTHER` совпадений нет.

Адресный план OCR содержит 9 страниц: 2 из ПД/АР и 7 рядом с кодовыми строками в источниках ПД/OTHER. Он не включает все 1 474 нечитаемых страницы и не запускается автоматически. Отсутствие совпадений для AR-043 или РД не доказывает отсутствие данных на чертеже.

Чтобы продвинуть любое из девяти правил, нужны минимум: подтверждённый РД/АР для того же объекта, редакция и утверждение источников, конкретная сущность чертежа, эквивалентные определения и единицы ПД/РД, проверка визуальной геометрии и соответствующей нормы или согласования. Неразобранные страницы остаются `UNKNOWN`.
