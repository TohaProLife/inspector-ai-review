# LAYER_ASSEMBLY: ограниченные предложения о слоях

28 сентября 2026. Отдельный opt-in профиль
`typed-pz002-pz017-layer-assembly-review-v1` рассматривает три кода:
`SPZU-032`, `AR-044`, `ZU-125`. Он читает сохранённый текстовый артефакт
конкретного запуска и проверенное решение по источнику. Выход
`layer-assembly-proposals-v1` содержит только адреса заголовков и
соседних текстовых блоков с SHA файла, страницы, блока и строки,
ограничением числа предложений и явным счётчиком отложенного OCR.

`SPZU-032` уже имеет отдельный профиль для таблицы дорожных одежд;
новый профиль не копирует его предложения. Для `AR-044` и `ZU-125`
соседство материала и подписи толщины остаётся
`ROW_ASSOCIATION_UNVERIFIED`; назначение типа и зоны также не
подтверждено. Поля `rawThickness` и `rawQuantity` равны `null`.
Все три кода имеют `ABSTAIN`, а `findingCount` и `parameterCoverage`
равны `null`. Нулевой поиск строк не означает отсутствие слоя.

В [предметном аудите](NEXT_LAYER_ASSEMBLY_AUDIT_20260928.md) проверены
оригинальные публичные PDF и пять листов с SHA. `F0154` с.22 имеет
`OCR_REQUIRED/TEXT_DECODING_ANOMALY`. Адресный
[OCR аудит](LAYER_ASSEMBLY_F0154_OCR_AUDIT_20260928.md) подтвердил
ошибки распознавания букв, римской цифры и границы строки; OCR
не используется как подтверждённая ячейка таблицы.

Worker pure и adapter тесты: 779/779 PASS. Независимый API verifier
воспроизвёл Python fixture и отклонил подмены источника, локатора,
счётчиков и попытку перенести толщину в факт. Release/save/seal/GET
и изолированный Compose отмечаются после отдельной проверки.
