# T61: полный исходный текст вложенных PDF Form

18 октября 2026. Принят отдельный явно выбранный профиль `pdfminer-analyzed-figures-whole-lines-v1`. Стандартный профиль и прежние потребители v1/v2 сохранены. На стенд изменение пока не установлено.

Новый профиль вызывает анализ pinned pdfminer ровно один раз для каждого внешнего Form. Сохраняются настоящие whole lines библиотеки, исходные пробелы/LF и полный путь вложенности. До рекурсивного анализа проверяются глубина и число native объектов. Канонический контракт допускает два профиля: старые пути длиной до 2 и новые до 64; проверка полного artifact, точная геометрия, quality и hash прежние.

Независимые проверки: 74 TS, 36 Python и 26 соседних тестов; 53 полных reader cases на каждом языке; пять новых исходных PDF с полными manual outputs, один некорректный оригинал и шесть отказов стандартного профиля. Проверены четыре поворота, CropBox/смещённое начало, вложенные пути, повторный анализ и отказы до callbacks. API/contracts typecheck и API build PASS. Изолированный wheel/sdist воспроизвёл 17 полных оригинальных результатов, включая полный реальный документ; девять ожидаемых отказов и 22 rule resources сохранены.

Полный исходный F0161 (38 страниц, SHA `ba76f0685eca5dadc591554af14cf82345397fbe2fd2b48d1e1cc26917d46bf1`) теперь даёт валидный v3 artifact: 4207 located строк и две unlocated строки положительного микротекста. Исходные значения и причины схлопывания сохранены, рамки не увеличены. Полный Python/TS content hash совпал: `4085e7d2b144a3ed9fccadb2b4e186c0ab7e9b8b7fee615842e4c0d6f3ce2779`. Quality: 33 candidate, 2 partial, 3 OCR-required страницы. Это характеристика text layer, не вероятность правильности инженерных выводов.

Существенное ограничение: отдельный авторский PDF содержит исходную строку внутри Form, которую clipping скрывает при рендеринге. Новый профиль сохраняет её как исходные native данные. Он не подтверждает видимость, отсутствие перекрытий или полноту документа. Будущие UI и потребители обязаны показывать этот статус; из integrity/hash не следует разрешение release или высокая уверенность.

Runtime, coverage 59 параметров/67 partial atoms/73 unsupported, qualified pairs 0 и probability null прежние.
