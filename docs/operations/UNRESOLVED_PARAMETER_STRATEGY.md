# Стратегия для 80 кодов `UNRESOLVED`

Реестр [`unresolved-parameter-strategy-v1.json`](unresolved-parameter-strategy-v1.json)
покрывает все 80 кодов класса `UNRESOLVED` из реестра 132 параметров ровно
по одному разу и в порядке исходного каталога. Это **проектный план** с
`executionPolicy=DESIGN_ONLY`, не набор работающих правил.

Скрипт `scripts/unresolved-parameter-strategy.py` добавляет к каждому коду:

- точный текст триггера и трёх требований к источникам из закреплённого каталога;
- вид требуемого доказательства, предполагаемое семейство извлечения и
  конкретную причину, почему сравнение одного числа, класса или факта наличия
  не выполняет условие каталога;
- следующую проверку, диктуемую `reasonCode` из существующего реестра;
- доступность исходников **только по метаданным** `document_manifest.jsonl`:
  объект, стадия, явный тег раздела и число документов со значением `OTHER`.

Входные SHA-256 закреплены в коде или самом реестре. Учитываются только строки
`TRAIN_PUBLIC` + `INCLUDE` + `PUBLIC_TRAIN` — 203 документа. `RD_ID_MIXED` и
`UNKNOWN` показаны отдельно, без превращения в РД. Значение `null` для числа источников с
точным тегом раздела означает, что каталог не дал сопоставимого тега, а не
нулевое число подходящих файлов. Документы `OTHER` нельзя автоматически
отвергать или считать нужным разделом.

Команда:

```bash
python3 scripts/unresolved-parameter-strategy.py
python3 -m unittest scripts/tests/test_unresolved_parameter_strategy.py -v
```

Снимок: [`output/unresolved-parameter-strategy-20260927/report.json`](../../output/unresolved-parameter-strategy-20260927/report.json),
SHA-256 канонической полезной нагрузки `ad60b8ab2b845bb2632f36aa4f2b85cdc43ee11c52e2fa85ba67da6e947c77ba`.
Из 80 кодов у 70 текст каталога не позволяет строго связать обе стадии с
тегами разделов манифеста. Ещё 10 имеют лишь односторонние кандидаты по
явным тегам. Число подтверждённых сопоставимых пар, findings и новых строк
coverage: **0**. Эти числа не оценивают возможности после просмотра PDF.

Пакеты пересекаются: строки показывают удобный порядок исследования источников,
не разделяют коды на исполняемую очередь. До проверки реальных страниц,
нормативной применимости, согласований и сопоставимой редакции все коды
остаются `UNRESOLVED` в текущем реестре. Внешний API в конкурсном решении не
предполагается.

Семь публичных семейных пачек уже сверены в
[итоговом отчёте](UNRESOLVED_PUBLIC_BATCH_SUMMARY.md): 83 записи из-за трёх
осознанных пересечений, ровно 80 уникальных кодов, все `ABSTAIN`.
Отчёт показывает реальные текстовые страницы, лимиты просмотра, адресные
OCR-очереди и причины, почему пара ПД/РД пока не допускается. Он не
повышает статусы исполнения каталога.
