# T14: площадь тротуарной плитки и согласованное изменение

Статус: принят 17.10.2026, 23:04 МСК. Evidence: `output/matrix-t14-20261017/acceptance.json`.

Приоритет — SPZU-026. Каталог требует выявлять изменение объёмов мощения без согласования заказчика. Первый атом ограничен площадью тротуаров из бетонной плитки. Тип плитки, участок, размещение по грунту/на кровле и база площади должны совпадать по отдельному решению инспектора. Другие объёмы, состав слоёв и полнота ведомости остаются gap.

## Исполняемый срез

- `SIDEWALK_TILE_AREA`, `m2`, DECIMAL, DIFFERENT, только PD_RD.
- Точные подписи: «Площадь тротуарного плиточного покрытия», «Площадь тротуаров из бетонной плитки». Число и единица должны находиться в полной исходной строке; диапазоны/альтернативы/посторонние числа отвергаются.
- Разделы ПД: SPZU/GP; РД: PP/GP.
- Условия: APPROVED_CHANGE_STATUS, SURFACE_TYPE_IDENTITY, ZONE_IDENTITY, точный ATOMIC_SUBRULE_SCOPE текущего ruleId.
- `approvedChangePresent=false` нужно явно в обоих исходных фактах. Актуальная согласованная редакция документа не доказывает отсутствие согласованного изменения.
- Новый bounded role SIDEWALK_TILE_PAVING: componentKey — конструкция/тип плитки, zoneKey — границы участка, operatingModeKey — по грунту/на кровле, measurementBasisKey — одинаковая база расчёта площади. Сравниваются все четыре поля.
- Новый role разрешается только точным policy с данным кодом/признаком/семейством/контекстами. Прежние пять DECREASE roles сохраняют прежний policy. Python typed identity проверяется только для собственного ATOMIC context, как TS.
- T13 fact bindings: каждая строка и каждое правило проверяются независимо. Ни полнота, ни отсутствие нарушения не наследуются от подтверждения пары.
- Gap: `PARTIAL_SUBRULES_ONLY:SIDEWALK_TILE_AREA_ONLY;OTHER_PAVING_QUANTITIES_AND_FULL_SCOPE_UNSUPPORTED`. Probability остаётся null, машинное расхождение — кандидат.

## Приёмка

100→110 и 100→90 дают candidate с полным сопоставимым контекстом; 100→100 без полноты даёт NEGATIVE_SCOPE_UNVERIFIED. Согласованное изменение, UNKNOWN статусы, чужая поверхность/участок/режим/база, непроверенное условие, неоднозначные строки блокируют квалификацию. Толщина 80мм, номер ГОСТ, общая площадь твёрдых покрытий, диапазон и альтернативы не заменяют площадь плитки.

Python/TS golden parity, durable PostgreSQL, browser SAVE/CAS/newrun, неизменность старых JSON и restart обязательны. Добавление атома меняет config release; прежние результаты остаются с прежним реестром.
