# Общий пакет подсказок для AREA_PROGRAM и DIMENSION_LAYOUT

28 сентября 2026. Первый `unresolved-review-config-v1` закрепляет SHA
конфигурации `c5aedccb8752ef365ea18298e1ed222f97abd207607b8caf5a18f23fd547bc85`.
Она задаёт 19 кодов: семь `AREA_PROGRAM` и 12 `DIMENSION_LAYOUT`.
Коды и порядок сверены с [реестром](../../services/worker/rules/parameter-family-registry-v1.json)
и [стратегией](unresolved-parameter-strategy-v1.json). Исходные открытые
F0126, F0154 и F0104 проверены по manifest SHA и физическим страницам;
это аудит словаря подсказок, а не подтверждение фактов.

Один evaluator использует только сохранённый `document-text-v2` конкретного
запуска и решения `CURRENT/APPROVED` с проверенным разделом и стадией.
Для каждой строки он хранит SHA PDF, текстового артефакта, блока и строки,
номер страницы, индекс блока/строки и bbox **блока**. Совпадение текста
помогает открыть место в PDF; bbox блока не доказывает строку таблицы,
геометрический размер, принадлежность элементу или применимую норму.
`OCR_REQUIRED` откладывается; длинные строки и усечение списка считаются
отдельно. Счётчик совпадений относится лишь к просмотренному текстовому
слою и не позволяет утверждать отсутствие параметра в документе.

Все 19 кодов возвращают `ABSTAIN`; `findingCount` и
`parameterCoverage` равны `null`. Конфигурация не содержит исполняемых
правил сравнения. `AR-042` и `SPZU-027` уже встречаются в других
review-only профилях, поэтому новый opt-in профиль должен быть
взаимоисключающим. Исходные ПД/РД пары и положительные экспертные решения
для этого пакета не утверждались.

Pure worker и adapter после исправления постраничной стадии и разбиения
строк прошли полный worker suite 751/751. Независимый API verifier принял
два Python fixture, включая смешанную карту стадий и U+2028,
отверг подмену SHA, ложные нулевые счётчики и drift конфигурации: 5/5;
API typecheck прошёл.
Web панель показывает причины `ABSTAIN`, счётчики и SHA-привязанные
локаторы; web typecheck и 72/72 теста прошли. Durable API хранит pinned
config в immutable release и заново проверяет конфигурацию, источник,
текст и sidecar при save/seal/authenticated GET. Synthetic PostgreSQL
проверил одну разрешённую строку-подсказку и отрицательные подмены;
последовательный suite 15 файлов/39 тестов прошёл. Изолированный Compose
следует отмечать только после его отдельной проверки.
Полный локальный `npm run check` после исправлений прошёл: API 296
тестов, web 72, worker 751 и сборка.

Первый изолированный Compose обнаружил ошибку пути к JSON в установленном
wheel: worker искал его в `site-packages/rules`, тогда как Docker копирует
в `/worker/rules`. Загрузка теперь использует существующий контракт
`INSPECTOR_RULES_DIR`, а локально — каталог исходников. Отдельный тест
переместил Python package и каталог правил, затем загрузил оба
SHA-закреплённых JSON; focused worker 11/11 прошли. Неудачный запуск
сохранён в [Compose-отчёте](UNRESOLVED_CONFIG_COMPOSE_20260928.md).
