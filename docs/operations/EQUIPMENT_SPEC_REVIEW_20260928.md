# EQUIPMENT_SPEC: навигация по спецификациям ОВ

28 сентября 2026. Отдельное семейство для `IOS4-077`, `IOS4-079` и
`PPM-112` строится поверх сохранённого `document-text-v2`.
[Предметный аудит](NEXT_UNRESOLVED_FAMILY_AUDIT_20260928.md) сверил по SHA
оригинальные разрешённые F0171/F0202 и шесть характерных страниц.
F0171 содержит строки спецификаций радиаторов и вентилятора, а также
расчётные страницы противодымных систем. F0202 содержит текст реестра
изменений и имеет смешанную стадию в публичном manifest. Из названия
листа нельзя назначить ему проверенный RD stage или текущую редакцию.

Pure worker `equipment-spec-run-review-v1` возвращает три `ABSTAIN` и
точные локаторы строки/блока/страницы с SHA. Он различает
`SCHEDULE_TOKEN`, `CALCULATION_PROSE`, `REGISTER_PROSE` и
`CONTEXT_UNRESOLVED`. Любой допустимый вход требует immutable решения
`CURRENT`/`APPROVED`, единственного PD или RD stage и секции OV;
смешанный источник без такого решения отклоняется. OCR_REQUIRED страницы
не считаются прочитанными.

Лид не связывает модель, расход, давление, теплоотдачу, количество,
помещение или систему в одну запись. У каждого локатора
`rowAssociationStatus=UNVERIFIED` и `systemAssignmentStatus=UNVERIFIED`;
`findingCount` и `parameterCoverage` равны `null`. Не установлены
утверждённые редакции и сопоставимая пара ПД/РД, поэтому результат не
является фактом или сравнением.

Отдельный opt-in профиль `typed-pz002-pz017-equipment-spec-review-v1`
подключён в worker/API/web. Pure worker и адаптер получили синтетические
тесты; независимый API валидатор принимает Python fixture и отвергает
подмены категории, локатора, геометрии и ложное отсутствие лида.
API перепроверяет immutable источник и текст при save/seal/GET.
Полный локальный `npm run check` прошёл: API 288, web 68, worker 732,
сборка. Последовательный PostgreSQL suite 13 файлов/37 тестов прошёл
без пропусков; синтетический `CURRENT`/`APPROVED` источник не заменяет
решение эксперта по реальному PDF. Первый общий прогон тестов поймал
таймаут старого насыщенного preview теста на 5,2 секунды при лимите
5 секунд; одиночный rerun прошёл, лимит этого теста увеличен до 15
секунд, повторный полный прогон прошёл. Изолированный
[Compose на исходном F0171](EQUIPMENT_SPEC_COMPOSE_20260928.md)
завершился 9/9 успешными заданиями, тремя `ABSTAIN` и нулём строк:
экспертного решения по источнику нет. Это доказывает транспорт и
безопасное воздержание, а не точность извлечения оборудования.
