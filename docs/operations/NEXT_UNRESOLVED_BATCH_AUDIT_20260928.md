## Вывод о v4

Лексический `unresolved-review-config-v4` для этих девяти кодов **не запускать**: он повторит заголовки, легенды и тематические фразы без операции наложения. Положительный либо нулевой счётчик таких лидов был бы ложной мерой пригодности. Минимальный будущий общий механизм имеет смысл только после отдельного геометрического extractor с проверяемыми координатными рамками, масштабом и преобразованием, адресами PDF/page/render SHA, фазой, зарегистрированными полигонами/точками и явным пространственным предикатом для каждого кода. При отсутствии любого такого доказательства — `ABSTAIN`, без фактов, находок и coverage. Эта проверка не утверждает ни одну пару ПД/РД и не меняет release profile.
