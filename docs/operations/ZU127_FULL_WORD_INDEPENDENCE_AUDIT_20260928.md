# ZU-127: независимая проверка полного списка слов, 28.09.2026

Для `zu127-window-table-proposals-v1` worker использует PyMuPDF `get_text("words", sort=False)`. API получил отдельный ограниченный провайдер `poppler-page-words.ts`: он заново читает исходный PDF через Poppler, проверяет полный SHA файла, число страниц, версию `pdftotext`, хеши XML и текстового вывода и возвращает **весь** список слов выбранной страницы. Проверка всего списка нужна для утверждения точных `wordIndex`, количества предложений и отсутствия иных подходящих строк. Выборочная сверка четырёх значений для этого недостаточна.

Исходный разрешённый `F0152`: SHA-256 PDF `99ec972d7dfe5039fca922e3120bd5e486f2a26518f78044d0850992c028e7af`, `TRAIN_PUBLIC / INCLUDE / PUBLIC_TRAIN`, 77 страниц. На физической странице 49 PyMuPDF выдаёт 132 слова, Poppler — 135; на странице 51 соответственно 175 и 173. Строгая проверка возвращает `WORD_COUNT_MISMATCH` для обеих страниц. Разница вызвана разной сегментацией/порядком парсеров; при этом адресная Poppler-сверка выбранных слов на страницах 49 и 51 прошла. Это подтверждает отдельные видимые надписи, **не** полный worker output.

Итог: четыре предложения worker v1 остаются локальной навигацией с `ABSTAIN`, `typedValues: null`, `findingCount: null`, `parameterCoverage: null`. V1 не подключается к durable release/save/seal/GET по результату выборочной сверки. Отдельный версионированный [Poppler v2](ZU127_POPPLER_V2_REVIEW_20260928.md) уже извлёк те же четыре адреса и прошёл локальную независимую API re-extraction полного списка слов из исходных байт. Это лишь review-only: границы табличных строк, роль источника и соответствие конкретного изделия в ПД/РД не подтверждены.

Среды пока различаются. На локальной машине обе стороны использовали Poppler `25.03.0`. В текущем isolated homeserver API контейнере установлен `25.12.0`, а worker контейнер не содержит `pdftotext`. Поэтому v2 пока не подключён к durable release/save/seal/GET и не объявлен прошедшим Compose. Перед runtime-интеграцией требуется одинаковая закреплённая версия Poppler либо общая версия извлечённого immutable word artifact с повторной серверной проверкой.

Проверки провайдера: 4/4 теста, включая исходные страницы 49/51 и fail-closed на несовпадении; API typecheck и `git diff --check` прошли. PDF временно извлечён из разрешённого публичного ZIP, не включён в репозиторий. Полные артефакты review v1 и исходные рендеры описаны в [аудите пяти семейств](SINGLETON_UNRESOLVED_FAMILY_AUDIT_20260928.md) и [предложениях ZU-127](ZU127_WINDOW_TABLE_PROPOSALS_20260928.md).
