# Ручная проверка OCR-строк: код и homeserver, 28 сентября 2026

В отдельном профиле с `ocrTableRows` реализован append-only журнал
`ocr-row-transcription-review-v1`. Он записывает только человеческое решение о
чтении конкретной строки таблицы. API при записи и чтении заново проверяет
сохранённые OCR и rule-артефакты, release/manifest, SHA PDF, страницы и
рендера, геометрию и индекс строки; привязка к коду или факту не происходит.
Для чтения нужны сессия и доступ к объекту; для записи — `REVIEW_DECIDE`,
CSRF и ключ идемпотентности. SQL-миграция `020` запрещает UPDATE/DELETE.

На локальной машине прошёл полный `npm run check`: API **192 passed / 22
skipped**, web **29 passed**, worker **641 passed**, сборка успешна. Полная
отдельная PostgreSQL интеграция после обновления миграций: **21/21**.
Новый тест PostgreSQL на синтетической OCR-странице проверил запись,
повтор команды, конфликт ключа, аудит и неизменяемость; это не решение по
реальному документу.
