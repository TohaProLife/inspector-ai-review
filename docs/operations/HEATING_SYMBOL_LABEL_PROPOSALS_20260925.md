## Граница класса и предложения

`HEATING_LOOP` здесь означает видимую возвратную красно-синюю спираль, тип которой подтверждён выноской `Регулятор для системы “теплый пол” Multibox C/RTL` на том же листе. В рамку включена петля, без верхнего вертикального подключения, нижних прямоугольных приборов и магистралей. Это **предложение класса по видимой схеме**, не подтверждение монтажа и не доказательство отсутствия аналога в РД.

| ID | Локальная область | Решение |
|---|---|---|
| `HEATING-AI-0001` | Левая спираль под подписью `267, 270` | `HEATING_LOOP`; связь с одним номером комнаты не установлена |
| `HEATING-AI-0002` | Правая спираль под подписью `271, 272` | `HEATING_LOOP`; связь с одним номером комнаты не установлена |
| `HEATING-AI-0003` | Прямоугольный прибор ниже первой спирали | Локальный сложный отрицательный пример для класса `HEATING_LOOP` |
| `HEATING-AI-0004` | Прямоугольный прибор ниже второй спирали | Локальный сложный отрицательный пример для класса `HEATING_LOOP` |
| `HEATING-AI-0005` | Прямоугольный прибор в соседнем помещении `277 ПУИ` | Локальный сложный отрицательный пример для класса `HEATING_LOOP` |
| `HEATING-AI-0006` | Прямой участок красно-синей магистрали `T11/T21` | Локальный сложный отрицательный пример для класса `HEATING_LOOP` |

В листе ПД пары `267,270` и `271,272` приведены в общей подписи. `room_id=null`, `room_relation=UNKNOWN` у обеих петель намерен: по одному схематическому фрагменту нельзя назначить петле уникальный номер. Для прибора в явно отделённом помещении 277 проставлены `room_id=277`, `room_relation=INSIDE`. При обучении **многоклассовой** модели приборы из отрицательных примеров следует дополнительно проверить и, если подтверждён класс `RADIATOR`, перевести в положительные метки этого класса. Нельзя автоматически считать их фоном.
