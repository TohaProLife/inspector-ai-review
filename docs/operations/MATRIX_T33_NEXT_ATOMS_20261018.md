Дата: 2026-10-18. Статус: **NO_GO_CURRENT_PUBLIC_PAIR**. Это результат проверки данных, не остановка общего проекта. Изменены только этот документ и `output/matrix-t33-20261018/research-*`. Runtime, registry, approvals, БД, контейнеры и runs не изменены. Браузер не использован.

## Решение

В пределах проверенного пакета нет следующего нового атома, который можно честно принять end-to-end. Ближайший по простоте предиката — **POS-087, только замена монолитного железобетона на сборный для одной подтверждённой лестницы**. Но доступная пара KR описывает конструктивное решение, а не автоматически утверждённую технологию ПОС/ППР. Снижать77 unsupported на основании этих строк преждевременно.

Следующий вариант — **KR-056, только каталоговый пример С345 на С245 для одной позиции металлопроката**. Он сохраняет приоритет по материальным декларациям, однако исследование снова подтвердило разрыв идентичности изделий и отдельный section gate. Массовая генерация regex по остальным77 параметрам не закрывает эти условия.

Практический порядок: сначала закончить приёмку T32; затем отдельный ограниченный поиск ровно недостающего доказательства для POS-087 — approved method authority и явное сопоставление одной операции/лестницы в ПД ПОС и РД/ППР. Если такого открытого документа нет, закрыть этот путь как EVIDENCE_ONLY и искать одну настоящую same-member пару KR-056. Отсутствие comparable public member блокирует реальную квалификацию. Оно не блокирует отдельную реализацию bounded предиката KR-056 для будущих строго сопоставленных фактов; интеграцию в coverage принимать только отдельным этапом. KR-060 без mapping и парковки без denominator не исследовались повторно.

Каталог: «Самовольное изменение критических технологий (например, монолит на сборный ЖБ)». Delivery audit требует описание операций и согласование изменения метода; источники ПОС и технологические карты ППР. Это не любой DIFFERENT конструктивного материала.

**ПД F0106 / KR / PDF37**, original SHA `ae8b16439650526a5ef6e1975c852fa38c2ab4466cd73ab725a47bcb32a6b655`:

- block7:0 `[106320,496608,508440,508608]`: `Лестницы запроектированы как монолитные железобетонные внутри объекта.`

**РД F0139 / KR / PDF4**, original SHA `d59c225e75d1e0227f08869b31165bd93bf85ed4b1da005c3e86ebc27023b73f`, block1:3 `[72000,1102371,798335,1114370]`:

**ПД F0112 / POS / PDF26**, original manifest SHA `a0bbb37fd25eed4a44c33cc22707c50a6a226d00106a1e6909c00b7881ec2768`:

- block3:1 `[99001,711970,571753,726010]`: `ограждений  и  пути  движения  к  лестнице  в  котлован  необходимо  установить` — лестница временного доступа, не доказательство технологии внутренней несущей лестницы.
- block15:0 `[154682,163330,538461,180080]`: `Работы по возведению монолитных железобетонных конструкций.` — общий заголовок; три соседних overlapping дубликата того же текста. Нельзя превращать совместное наличие слов на странице в единый stair-method fact. Здесь нужен отдельный layout/duplicate rejection, не глобальный page-text join.

**Минимальный будущий срез, пока не реализация.** Разрешить только категории `MONOLITHIC_REINFORCED_CONCRETE` и `PRECAST_REINFORCED_CONCRETE`, собственную категориальную единицу метода, направленный каталоговый переход. Никаких числовых рангов. Сохранить original raw fragments и независимую source-bound реконструкцию. Положительный controlled scenario должен честно менять реальную методическую декларацию в новом synthetic source, а не одно слово общего заголовка.

Нужны reviewed same component/zone/construction stage, явное назначение операции, approved/current source reviews, approved-change status, atomic scope. Дополнительная authority должна связывать **реальную методическую декларацию** ПОС/ППР с source ID/SHA/page/target и текущим review hash; если используется cross-document KR context, он только идентифицирует элемент и не подменяет method authority. Generic reference, section filename, whole-file scope и равенство слова «монолит» не заменяют proof. Нельзя просто переименовать KR в POS или объявить РД конструкций технологической картой.

Без такого источника — UNKNOWN/EVIDENCE_ONLY; равенство не доказывает полноту отрицательной проверки; probability=null. Даже после будущего атома последовательность всех операций и другие технологии остаются unsupported.

Самый узкий extraction срез без OTHER gate — ПД F0105 PDF14, реальные stage PD/section KR. Полные строки24:0,25:0,28:0,30:0 описывают крепление через распределительные пояса, второй ярус из трёх двутавров70Б3 и непосредственно прилегающую скобку `сталь класса C245 ГОСТ 27772-2015`. Безопасный evidence scope — **70Б3 / три двутавра / второй ярус / распределительный пояс**, категория C245, не мм и не число245. Не присваивать автоматически этот класс70Б2 первого/третьего яруса: скобка непосредственно следует после70Б3. Строки высотой12000mpt, общий left99408, vertical gaps8670/8640/8880mpt. Whole-page join недопустим. Первое evidence сохраняет исходный raw C245; Unicode alias нормализуется только в категории С245. Категориальная unit должна быть отдельной, raw физическая unit отсутствует.

Первая строка содержит продолжение предыдущего pipe-standard clause; parser должен сохранять полные исходные строки и однозначные token ranges, а не искать ближайший класс по всему блоку.
