# Доступ к проекту и материалы передачи

Проверено 29 сентября 2026 года. Это фактический аудит текущей рабочей копии и доступности репозитория, а не юридическое заключение или изменение условий лицензирования проекта.

## Доступ для жюри

GitHub REST API с существующей авторизацией подтвердил:

| Поле | Результат |
|---|---|
| Репозиторий | <https://github.com/FreeTok/HackatonAI> |
| `private` | `true` |
| `permissions.pull` | `true` |
| `permissions.push` | `true` |
| `permissions.triage` | `true` |
| `permissions.maintain` | `false` |
| `permissions.admin` | `false` |

Без авторизации запрос возвращает `404`. Обычной ссылки недостаточно для участника жюри, которому не предоставлен доступ. Проверка не меняла видимость и не отправляла приглашения. Учётные данные использованы только в памяти процесса; их значения не включены в этот документ или отчёт.

Два варианта передачи:

1. Владелец репозитория приглашает согласованные GitHub-аккаунты жюри. После принятия приглашения следует проверить открытие репозитория с учётной записью получателя.
2. Передать подготовленный архив исходников без `.git`, локальных секретов, рабочих данных и материалов дизайн-анализа. В архиве зафиксировать revision, инструкцию запуска, результаты проверок, ограничения и необходимые лицензии зависимостей. Передавать через согласованный организаторами канал; изменение приватности репозитория для этого не требуется.

Пакет из текущей рабочей директории должен учитывать незакоммиченные исправления. `git archive HEAD` сам по себе их не включает. Копирование всей директории также непригодно: оно захватит локальные runtime-файлы и исследовательские материалы.

## Проверка явных секретов

В текущем срезе проверены 1 095 текстовых файлов из 1 226 tracked-файлов. В истории всех локально доступных refs проверены 2 546 Git blobs, всего 125 754 737 байт, без пропуска крупных blobs. Проверялись характерные форматы приватных ключей, GitHub, AWS и ряда AI/provider-токенов. Для текущих файлов дополнительно проверены URL с паролями и литералы с названиями secret/token/password.

Явных ключей перечисленных форматов не обнаружено. Найденные URL с паролями относятся к локальным примерам, тестам или подстановкам переменных Compose; остальные совпадения — тестовые литералы. Tracked-файлов с именами приватных ключей, `.env` с рабочими значениями или credential-файлов не обнаружено.

Это ограниченная проверка сигнатур, а не подтверждение отсутствия любых секретов: неизвестные форматы, двоичные вложения и refs, недоступные в локальном clone, требуют отдельной проверки при изменении состава поставки. Значения совпадений в отчёт не включены.

Из архива исключить `.git/`, `.tmp/`, `tmp/`, `var/`, `runtime/`, `downloads/`, `node_modules/`, виртуальные окружения, coverage, логи и рабочие `.env`/credential-файлы. `.env.example` сохранить как шаблон. `output/` содержит в том числе уже tracked концептуальные слайды; правило `.gitignore` не исключает ранее добавленные файлы из Git или архива автоматически.

Аудит фиксирует расхождения и не делает вывода о допустимости конкретного способа распространения. Код, зависимости и лицензия самого проекта этой проверкой не заменялись. Корневой `LICENSE` для собственного кода в проверенном срезе отсутствует; условия его передачи определяет владелец проекта и правила конкурса.

## Референсы и собственные графические материалы

- Четыре tracked-файла в `docs/assets/mobbin/` — `airwallex-review-bill.jpg`, `aws-upload-status.jpg`, `semrush-content-diff.jpg`, `vanta-tests-dashboard.jpg`. [UI_REFERENCES.md](UI_REFERENCES.md) определяет их как водяные preview для внутреннего дизайн-анализа и сохраняет исходные ссылки. **Исключить эти изображения из передаваемого release-архива**; ссылки и текстовые выводы можно сохранить. Разрешение на их перераспространение в проверенных файлах не зафиксировано.
- Локальная папка `design-research/` содержит записи изучения Cloudflare/Mobbin, screenshots и исходный SVG sprite. Это исследовательские материалы; исключить папку из release-архива. Её README предупреждает о неподтверждённых правах повторного использования dashboard sprite. В текущем tracked `apps/web/public/` такого sprite нет; рабочие glyphs импортируются из пакетов иконок.
- В `apps/web/public/images/` находятся четыре `architecture-*.webp`. [ParticleBuilding.tsx](../apps/web/src/design-system/ParticleBuilding.tsx) использует `architecture-cutout.webp`. Авторство, источник и права на эти изображения в проверенных tracked-документах **не подтверждены**. Перед публичным распространением следует зафиксировать происхождение у автора/владельца материалов; аудит не приписывает их Antimetal или другому источнику.
- `fixtures/public-review/`, `apps/web/public/evidence/` и части `datasets/` содержат исходные или производные материалы конкурсного корпуса. Метка public/train описывает доступность в рамках текущего workflow и сама по себе не устанавливает право общего перераспространения. Состав передачи этих материалов следует согласовать с правилами организатора; полный локальный `downloads/` в архив не включать.

Подготовка такого архива и предоставление доступа жюри — отдельные действия. Настоящий документ их не выполняет и не меняет разрешения репозитория.
