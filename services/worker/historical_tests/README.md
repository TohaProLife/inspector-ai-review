# Исторические проверки с внешними исследовательскими данными

Восемь модулей сохранены без изменения байтов из предыдущего коммита. Они требуют output-артефакты, которые не входят в публичный исходный пакет. Эти модули уже были исключены из принятого переносимого набора V9; перенос в отдельный каталог сохраняет историю и позволяет выполнять обычный npm run test:python из чистого Git checkout.

Их результаты не включены в 8480 pass/246 skipped переносимой приёмки. Прежние assertions не удалены и не ослаблены. Причины и необходимые output-пути перечислены в docs/operations/PORTABLE_TESTS_20261020.md. Для явного запуска после подготовки внешних данных:

```bash
PYTHONPATH=services/worker:services/worker/historical_tests python3 -m unittest discover -s services/worker/historical_tests -v
```

Обычный Python runner обнаруживает тесты только в services/worker/tests. Общий рекурсивный pytest может включить и эти исторические проверки; используйте документированный runner для переносимой приёмки.
